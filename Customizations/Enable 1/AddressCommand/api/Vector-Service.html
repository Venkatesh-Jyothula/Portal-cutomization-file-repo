Vector Service

Vector Service provides NetWorks feature data as GeoJSON geometries with additional properties required for rendering on the client.

Only vector geometries published in DDC are supported.

Job Support

All requests working with feature data accept additional optional parameters {jobs} and {force} passed in the query string.

Format

?jobs={jobs}&force={force}

Parameters

Name Type Mandatory Description
jobs String N Comma separated list of job names.
force String N When set to 1, Vector Service forces the refresh of deltas from database. When missing or any other value, job deltas are cached in memory and refreshed only after the cache becomes stale. Default is 10 minutes.

Sample Request

http://machinename/NetworksVectorService/data?jobs=JOB1,JOB2

http://machinename/NetworksVectorService/data/323/123454?jobs=JOB3

http://machinename/NetworksVectorService/tooltip/323/123454?jobs=JOB3&force=1

3D Support

/data and /geometry endpoints support additional query parameter dims with allowed values of 2 (default) and 3. When 3 is passed in (or configuration parameter GeoJSON:Dimensions is set to 3), the vertices in GeoJSON output include the Z dimension as stored in the DDCs.

Sample Request

http://machinename/NetworksVectorService/data/323/123454?dims=3

Notes

  • Polyline and polygon clipping is turned off when 3D geometries are requested. Configuration parameters can't override this behavior.
  • Vertex reduction (dependent on resolution) follows the configuration in the GetFeatures endpoint. The default for vertex reduction is on, which may cause the geometries to be distorted if they should be visualized with a different resolution. If you want full geometries to be returned, turn off vertex reduction in the configuration.

Component view attributes

/data and /geometry endpoints support additional query parameter attrs with allowed values of 0 (default) and 1. When 1 is passed in, attributes property is added to the GeoJSON Feature properties. The attributes is an JSON object, whose properties are the component view fields. Geometry and binary fields are not added to the output.

Sample Request

http://machinename/NetworksVectorService/geometry/323/1027199?g=1&attrs=1
