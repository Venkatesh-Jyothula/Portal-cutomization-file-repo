SetFullExportSchedule

This API is obsolete.

Set the time and date to run a Full Export.

GET

Request URL Template

http://{HostName}/{CIMManagementServiceName}/Export/Full/Schedule/Set?starttime=xxxxxx&startDate=xxxxxxxx

Request Parameters

Parameter Name Description
starttime The time to start the Full Export in 24 hour hhmmss format. For example, 1:15 pm (13:15:00) would be 131500.
startdate The date to run the Full Export in yyyyMMdd format. October 3, 2017 would be 20171003.

Sample Request

http://{HostName}/{CIMManagementServiceName}/Export/Full/Schedule/Set?starttime=091800&startdate=20171027

Sample Response

{
       "StartDate": "10/27/2017",
       "StartTime": "09:18:00",
       "Success": true,
       "Message": "Full Export scheduled to run."
   }
