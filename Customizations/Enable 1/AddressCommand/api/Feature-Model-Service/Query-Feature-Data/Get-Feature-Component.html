Get Feature Component

Returns the requested component for the specified feature instance that matches the G3E_FID value, and G3E_CID if component is repeating.

GET

Request URL Template

http://{hostname}/{service instance}/data/{featureName}/{fid}/{componentName}[/{cid}]?[{oDataOptions}][&Jobs={listOfJobNames} | ActiveJob={jobName}]

Request Parameters

Parameter Name Optional or Required Description
featureName Required Specifies the model feature type to retrieve data for.
fid Required Specifies the G3E_FID value for the model feature to retrieve component data for.
componentName Required Specifies the feature component type to retrieve.
cid Optional Specifies the G3E_CID value for the repeating component instance to retrieve.
oDataOptions Optional See the OData Options section below.
listOfJobNames Optional Specifies a comma separated list of HxGN NetWorks Core jobs whose pending edits will participate in the query and response.
jobName Optional Specifies the active HxGN NetWorks Core job whose pending edits will participate in the query and response.

OData Options

Since a specific component instance of the feature has been selected, the only OData parameter that applies is $select parameter.

  • $select={attributes} - a comma separated list of the feature attributes to return in the response. Usually, the $select clause is nested in the componentList of the $expand option (e.g. "$expand=Substation_Record($select=Sub_Name,Sub_Type)" where Sub_Name and Sub_Type are attributes of the Substation_Record component).

Sample Request

http://localhost/NetWorksFeatureModelService/data/SubStation/7693135/Hyperlink_Record/2?$select=G3E_CID,FILEPATH&ActiveJob=16205

Sample Response A JSON response is returned. If the G3E_GEOMETRY attribute is included, it will be formatted as GeoJson.

{
    "@odata.context": "http://localhost/NetWorksFeatureModelService/data/$metadata#Substation(3747378)/HYPERLINK_RECORD(G3E_CID,FILEPATH)",
    "value": 
    {
       "G3E_CID": 2,
       "FILEPATH": "InstallInstructions.txt"
    }
}
