Get Feature By Fid

Returns the requested feature data for the feature instance that matches the specified G3E_FID value.

GET

Request URL Template

http://{hostname}/{service instance}/data/{featureName}/{fid}?[{oDataOptions}][&Jobs={listOfJobNames} | ActiveJob={jobName}]

Request Parameters

Parameter Name Optional or Required Description
featureName Required Specifies the model feature type to retrieve data for.
fid Required Specifies the G3E_FID value for the model feature to retrieve data for.
oDataOptions Optional See the OData Options section below.
listOfJobNames Optional Specifies a comma separated list of HxGN NetWorks Core jobs whose pending edits will participate in the query and response.
jobName Optional Specifies the active HxGN NetWorks Core job whose pending edits will participate in the query and response.

OData Options

Since a specific instance of the feature type has been selected, the only OData parameters that apply are the $expand and $select parameters.

  • $expand={featureComponentsRelationships} - a comma separated list of components and relationships of the feature instance to include in the response.
  • $select={attributes} - a comma separated list of the feature attributes to return in the response. Usually, the $select clause is nested in the componentList of the $expand option (e.g. "$expand=Substation_Record($select=Sub_Name,Sub_Type)" where Sub_Name and Sub_Type are attributes of the Substation_Record component).

Sample Request

http://localhost/NetWorksFeatureModelService/data/SubStation/7693135?$expand=substation_record,substation_ar,hyperlink_record($select=G3E_CID,FILEPATH),common_record&ActiveJob=16205
