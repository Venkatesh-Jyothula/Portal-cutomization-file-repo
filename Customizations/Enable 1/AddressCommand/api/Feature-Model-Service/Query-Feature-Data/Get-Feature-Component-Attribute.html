Get Feature Component Attribute

Returns the requested component attribute for the specified feature instance that matches the G3E_FID value, and G3E_CID if component is repeating.

If the request route ends with /$value, then only the raw value of the component attribute is returned in the response (i.e. without the OData Json wrapper).

GET

Request URL Template

http://{hostname}/{service instance}/data/{featureName}/{fid}/{componentName}[/{cid}]/{attributeName}[/$value]?[Jobs={listOfJobNames} | ActiveJob={jobName}]

Request Parameters

Parameter Name Optional or Required Description
featureName Required Specifies the model feature type to retrieve data for.
fid Required Specifies the G3E_FID value for the model feature to retrieve component attribute data for.
componentName Required Specifies the feature component type.
cid Optional Specifies the G3E_CID value for the repeating component instance to retrieve.
attributeName Required Specifies the feature component attribute to return.
listOfJobNames Optional Specifies a comma separated list of HxGN NetWorks Core jobs whose pending edits will participate in the query and response.
jobName Optional Specifies the active HxGN NetWorks Core job whose pending edits will participate in the query and response.

Sample Request

http://localhost/NetWorksFeatureModelService/data/SubStation/3747375/Substation_Record/Sub_Name?ActiveJob=16205

Sample Response A JSON response is returned.

{
"@odata.context": "http://localhost/NetWorksFeatureModelService/data/$metadata#Substation(3747375)/SUBSTATION_RECORD/SUB_NAME",
"value": "MADISON KIPP"
}

Sample Request 2

http://localhost/NetWorksFeatureModelService/data/SubStation/3747375/Substation_Record/Sub_Name/$value?ActiveJob=16205

Sample Response 2 Just the value of the Sub_Name attribute is returned.

"MADISON KIPP"
