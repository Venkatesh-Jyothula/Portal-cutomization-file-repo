Update Existing Feature

Updates the feature instance that matches the specified G3E_FID value and returns the requested feature information.

This method is invoked via an Http Put request because it implements a full replace operation on the input components - not a partial update of attributes. The smallest object that can be updated is a single feature component - not a single attribute. Hence, the normal workflow is for the client to first fetch the feature components that have attributes that need to be updated, then update those attributes, then call this method to replace the component in the feature.

This method can also be used to insert a new instance of a repeating component in the feature by providing the component object without a G3E_CID value or setting the G3E_CID value to zero.

PUT

Request URL Template

http://{hostname}/{service instance}/data/{featureName}/{fid}?[{oDataExpandSelectOptions}][&ActiveJob={jobName}]

Request Parameters

Parameter Name Optional or Required Description
featureName Required Specifies the model feature type that is being edited.
fid Required Specifies the G3E_FID value for the model feature instance that is being edited.
oDataExpandSelectOptions Optional The $expand={componentList} and $select={attributeList} OData query parameters can be used to control how much information about the newly updated feature to return in the response. Usually, the $ select clause is nested in the componentList (e.g. "$ expand=Substation_Record($ select=Sub_Name,Sub_Type)" where Sub_Name and Sub_Type are attributes of the Substation_Record component).
jobName Optional Specifies the active HxGN NetWorks Core job that will hold the edits.

Request Put Body The Http Put body of the request specifies a Json object that defines the new values for the feature. See examples below.

Sample Request

http://localhost/NetWorksFeatureModelService/data/SubStation/7688101?$expand=Substation_Record,Hyperlink_record,Substation_AR,Common_Record&ActiveJob=16205

Sample Post Body In this example, the Http Put body updates values for several attributes of the SUBSTATION_RECORD and COMMON_RECORD components, defines one new instance of the HYPERLINK_RECORD repeating component, and updates the geometry for the SUBSTATION_AR primary geographic component. Note that G3E_GEOMETRY attributes are populated using standard GeoJson syntax. Note also that the new instance of the HYPERLINK_RECORD repeating component omitted the G3E_CID value (which indicates an insert instead of an update of an existing component).
