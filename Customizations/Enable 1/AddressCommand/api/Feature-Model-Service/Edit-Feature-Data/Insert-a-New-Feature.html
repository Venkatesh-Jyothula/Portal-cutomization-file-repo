Insert a New Feature

Returns a new instance of the specified feature type.

POST

Request URL Template

http://{hostname}/{service instance}/data/{featureName}?[{oDataExpandSelectOptions}][&ActiveJob={jobName}]

Request Parameters

Parameter Name Optional or Required Description
featureName Required Specifies the model feature type to create a new instance for.
oDataExpandSelectOptions Optional The $expand={componentList} and $select={attributeList} OData query parameters can be used to control how much information about the newly created feature to return in the response. Usually, the $ select clause is nested in the componentList (e.g. "$ expand=Substation_Record($select=Sub_Name,Sub_Type)" where Sub_Name and Sub_Type are attributes of the Substation_Record component).
jobName Optional Specifies the active HxGN NetWorks Core job that will hold the edits.

Request Post Body The Post body of the request specifies a Json object that defines the new feature. The minimum input contains a Json object that defines just the G3E_FNO type for the new feature. The maximum input would supply values for all attributes of the feature's components (including repeating components). See examples below.

Sample Request

http://localhost/NetWorksFeatureModelService/data/SubStation?$expand=Substation_Record,Hyperlink_record,Substation_AR,Common_Record&ActiveJob=16205

Sample Post Body

{
  "G3E_FNO": 326
}
