Get Metadata for Model Features

Returns metadata about all feature types in the published feature model.

GET

Request URL Template

http://{hostname}/{service instance}/metadata/modelfeatures/{filter?}

Request Parameters

Parameter Name Optional or Required Description
filter Optional Controls what type of metadata is returned in the response. Possible values are as follows: (1) - default response includes basic metadata about the feature. (2) all - include metadata for all components, attributes and relationships of the feature. (3) components - include metadata about the components of the feature. (4) relationships - include metadata about the relationships of the feature. (5) components, relationships - include metadata about the components and relationships of the feature.

Sample Request

http://hostname/NetworksFeatureModelService/metadata/modelfeatures/relationships
