Get Metadata for Model Feature by Fno

Returns metadata about a specific feature type in the published feature model.

GET

Request URL Template

http://{hostname}/{service instance}/metadata/modelfeature/{fno}

Request Parameters

Parameter Name Optional or Required Description
fno Required Specifies the G3E_FNO value of a specific feature.

Sample Request

http://hostname/NetworksFeatureModelService/metadata/modelfeature/326
