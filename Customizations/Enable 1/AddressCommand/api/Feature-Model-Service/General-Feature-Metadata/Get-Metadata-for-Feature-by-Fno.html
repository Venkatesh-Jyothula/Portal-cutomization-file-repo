Get Metadata for Feature by Fno

Returns metadata about the specific HxGN NetWorks Core feature type.

GET

Request URL Template

http://{hostname}/{service instance}/metadata/feature/{fno}

Request Parameters

Parameter Name Optional or Required Description
fno Required Specifies the G3E_FNO value of a specific feature.

Sample Request

http://hostname/NetworksFeatureModelService/metadata/feature/326
