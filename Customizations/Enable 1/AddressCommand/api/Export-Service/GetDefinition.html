GetDefinition

Gets the feature layers definition based on the configured export format.

GET

Request URL Template

http://{HostName}/{ExportServiceName}/definition

Remarks

Returns the feature layers definition. In the case of redline export, this method returns a single feature layer with feature classes corresponding to the defined redline categories. This information is important when creating a new data source.
