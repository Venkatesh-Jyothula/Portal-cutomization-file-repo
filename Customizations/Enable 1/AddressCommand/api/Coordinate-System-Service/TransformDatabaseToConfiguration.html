TransformDatabaseToConfiguration

Transform coordinates of 1 or 2 points fromdatabasetoconfigurationcoordinate system for specified NetWorks configuration.

Axis orientation of coordinate systems is ignored and the method always assumes axis horizontal-vertical orientation ((X, Y), (Easting, Northing) or (Longitude, Latitude)) regardless of coordinate system parameters.

All numeric parameter values use . as decimal separator. No grouping separator is allowed.

GET

Request URL Template

/configuration/{configuration}/dbtoconfig?x={x}&y={y}[&z={z}][&x1={x1}][&y1={y1}][&z1={z1}][&n={dimensions}]

Request Parameters

Parameter Name Description
configuration NetWorks configuration
x X ordinate of 1st point
y Y ordinate of 1st point
z Z ordinate of 1st point. Optional. When not present, 0 is assumed.
x1 X ordinate of 2nd point. Optional.
y1 Y ordinate of 2nd point. Optional.
z1 Z ordinate of 2nd point. Optional. When not present, 0 is assumed.
n Number of dimensions. Optional. Allowed values: 2, 3. When not present, 2 is assumed. Affects number of dimensions in return value.

Sample Request

http://machinename/NetworksCoordinateSystemService/configuration/NETWORKS/dbtoconfig?x=1303620&y=7055284

Sample Response

[
    4480851.860617144,
    5917510.0418096054
]

Sample Request 2

http://machinename/NetworksCoordinateSystemService/configuration/NETWORKS/dbtoconfig?x=1303620&y=7055284&z=0&n=3

Sample Response

[
    4480851.860617144,
    5917510.0418096054,
    0.0
]
