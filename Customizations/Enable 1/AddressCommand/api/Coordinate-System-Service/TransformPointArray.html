TransformPointArray

Transform coordinate array from source to destination coordinate system.

POST

Request URL Template

/configuration/{configuration}/transform?s={s}&d={d}[&n={n}][&iao={iao}]

Request Parameters

Parameter Name Description
configuration NetWorks configuration
s Source coordinate system name. This can either be a valid coordinate system defined within the configuration or a valid EPSG code. A valid EPSG code should be prefixed by 'EPSG:' (example 'EPSG:3857').
d Destination coordinate system name. This can either be a valid coordinate system defined within the configuration or a valid EPSG code. A valid EPSG code should be prefixed by 'EPSG:' (example 'EPSG:3857').
n Number of dimensions. Optional. Allowed values: 2, 3. When not present, 2 is assumed. Affects number of dimensions in both input and output.
iao Flag: ignore axes ordering. Optional. Allowed values: 0, 1. When 0, axis ordering is honored according to coordinate system parameters in both input and output. When 1, axis ordering is ignored and all values are expected in X,Y ordering ((X, Y), (Easting, Northing), (Longitude, Latitude)). When not present, 0 is assumed. Affects number of dimensions in return value.

Sample Request

http://machinename/NetworksCoordinateSystemService/configuration/NETWORKS/transform?s=EPSG:3857&d=GK4

Sample Request body

[
    1303620.0,
    7055284.0,
    1303621.0,
    7055285.0
]

Sample Response

[
    4480851.860617144,
    5917510.0418096054,
    4480852.4607003834,
    5917510.6356232725
]
