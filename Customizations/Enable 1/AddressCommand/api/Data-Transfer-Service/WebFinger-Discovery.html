WebFinger Discovery

Returns WebFinger discovery document for the service. This can be used to retrieve the URL of the OpenID Connect issuer and the Client Id to be used by the mobile devices.

This method does not require authentication.

Request

URI

GET /.well-known/webfinger?resource={user}&rel=http://openid.net/specs/connect/1.0/issuer

Parameters

Name Type Mandatory Description
user String Y User name. Value is not important, the service will return the same response for any value.

Response

When OpenID Connect issuer is configured in OpenIdConfig.json, its URL is returned in the href of the link with rel=http://openid.net/specs/connect/1.0/issuer.

There are additional parameters returned:

  • client_id under the properties of link with rel=http://openid.net/specs/connect/1.0/issuer. Value is mapped from configuration value infrastructureServiceAuthentication:ClientId. client_id is expected to be used by public clients (those which do not require client secrets) for direct communication with OIDC.

  • link with rel=web_authenticator href value is mapped from configuration value infrastructureServiceAuthentication:WebAuthenticatorUri.
    When present, the client should use this as the entry URI for the Web Authenticator flow.

{
    "subject": "acct:user1",
    "links": [
        {
            "rel": "http://openid.net/specs/connect/1.0/issuer",
            "href": "http://localhost:8080/auth/realms/NetWorks",
            "properties": {
                "client_id": "NWM"
            }
        },
        {
            "rel": "web_authenticator",
            "href": "http://localhost/MobileAuthenticatorService/mobileauth/OpenIdConnect"
        }
    ]
}
