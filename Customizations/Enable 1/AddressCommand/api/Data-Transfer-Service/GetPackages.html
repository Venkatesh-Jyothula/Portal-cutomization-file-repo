GetPackages

Returns a list of packages available for download on the server.

Request

URI

GET /package[?type={type}]

Parameters

Name Type Description
type string Type of package to retrieve. If not specified, all types are retrieved.

Response

Normal response (200)

List of all available packages.

{
  "packages": [{
    "id", "ELECTRIC_LV_ALL_20200801T085500",
    "package": "ELECTRIC_LV_ALL",
    "type": "nwcmsubset",
    "timestamp": "20200801085500"
    "description": "Electricity Low Voltage - All regions",
    "descriptions": {
      "cs": "Elektřina ...",
      "de": "Strom ..."
    },
    "size": 655236,
    "version": "1.0"
  }]
}

Authentication failure (401)

Returned when authorization token is missing or invalid.
