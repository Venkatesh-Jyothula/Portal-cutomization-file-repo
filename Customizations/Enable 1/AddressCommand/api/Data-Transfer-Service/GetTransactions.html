GetTransactions

Get list of committed transactions by search criteria.

Request

URI

GET /transactions?from={from}&to={to}&$skip={$skip}&$top={$top}&{attribute}={value}[&{attribute}={value}]

Parameters

Name Type Mandatory Description
from Date N Start timestamp, formatted as YYYYMMDDHHMMSS. When not specified, all transactions are read from the start.
to Date N End timestamp, formatted as YYYYMMDDHHMMSS. When not specified, upper limit is not enforced.
$skip Number N Number of records to skip.
$top Number N Maximum number of records to return. Server imposes its own limit which cannot be overridden by this parameter.
{attribute} String N Arbitrary attribute of package to filter on (e.g. type). All transactions which have {attribute} value equal to {value} in package.json file are returned.
