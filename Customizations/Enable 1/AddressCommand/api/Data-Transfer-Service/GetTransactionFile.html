GetTransactionFile

Returns contents of a file from a committed transaction.

Request

URI

GET /transaction/{tid}/file/{file}[?opt={opt}]

Parameters

Name Type Mandatory Description
tid String Y Transaction identifier
file String Y File name or file path, URL-encoded
opt String N Default 0. When not 0, file does not have to exist

Response

Normal response (200)

File content.

No content (204)

Returned if optional parameter opt is not 0 and file does not exist.

Bad request (400)

Returned when the request has invalid parameters.

{
    "Success": false,
    "ErrorCode": "ERR_TRANSACTION_NOT_FOUND",
    "ErrorMessage": "No transaction found for provided tid"
}

{
    "Success": false,
    "ErrorCode": "ERR_FILE_NOT_FOUND",
    "ErrorMessage": "No file found for provided transaction tid and file name"
}

Authentication failure (401)

Returned when authorization token is missing or invalid.

Forbidden (403)

Returned when the request points to an existing object to which the current user has no access rights.

{
    "Success": false,
    "ErrorCode": "AccessDenied"
}
