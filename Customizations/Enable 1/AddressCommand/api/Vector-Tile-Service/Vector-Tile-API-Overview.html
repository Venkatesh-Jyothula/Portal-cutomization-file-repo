Vector Tile API Overview

The HxGN NetWorks Vector Tile Service is a standard RESTful web service that provides an API to retrieve vector tiles. Vector tiles contain vector data instead of a rendered image. They contain geometries and attribute data used by the style specification document — in a compact, structured format. The Vector Tile Service is developed using the Mapbox Vector Tile (MVT) Specification, which explicitly provides information about file formats and extensions, projections and bounds, and the internal structure of the vector tiles.

  • Tiles are generated on demand and cached at the specified location.
  • Tiles are encoded using Google Protobufs (PBF) and have a file extension of .mvt.
  • Uses Web Mercator (EPSG:3857) as the projection.
  • Includes support for a single tile matrix set that follows the Google zoom levels.
  • Tile size is fixed to 512 x 512.
  • Includes only attributes that are published as part of the HxGN NetWorks Core component view.
  • Follows the Slippy Map Tilenames Specification when representing the file naming convention.
    • http://hostname/NetworksVectorTileService/zoom/x/y.mvt

The Vector Tile Service also provides an API to get a Mapbox Style Specification document. A Mapbox Style Specification defines the visual appearance of a map: what data to draw, the order to draw it in, and how to style the data when drawing it. Before the Style Specification document can be retrieved through the API, administrators have to publish the document during the deployment of the Mapbox Vector Tile Service.

  • Uses a style filtering approach similar to HxGN NetWorks Core where the attributes published as part of the MVT file are used when defining filters.
  • Display is controlled by specifying the minimum and maximum zoom levels similar to the legend entry minimum and maximum display scale.
  • Allows data-driven styling of spatial data based on the attributes published as part of the MVT file.
  • Supports scale dependent display of symbols and text.
  • Similar to HxGN NetWorks Core, the label text content is derived from attributes published as part of the MVT file.
  • Mapbox plugin libraries are available for Leaflet and OpenLayers that can render the Mapbox vector tiles using the Mapbox style specification. Mapbox also provides their own Mapbox GL library to render interactive maps.
