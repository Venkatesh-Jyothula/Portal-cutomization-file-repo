Get Style JSON

Returns the MapBox JSON style specification document. A Mapbox style specification is a document that defines the visual appearance of a map: what data to draw, the order to draw it in, and how to style the data when drawing it.

GET

Request URL Template

http://{hostname}/{service instance}/Style.json

Sample Request

http://hostname/NetworksVectorTileService/Style.json
