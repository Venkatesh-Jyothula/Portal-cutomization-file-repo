Get Tiles JSON

Returns the Tile JSON metadata. Tile JSON is an open standard for representing map metadata.

GET

Request URL Template

http://{hostname}/{service instance}/Tiles.json

Sample Request

http://hostname/NetworksVectorTileService/Tiles.json

Sample Response

A Json response is returned.
