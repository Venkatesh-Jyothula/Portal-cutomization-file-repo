Get Tile

Returns the vector tile in the MapBox vector tile file format using the specified zoom level, tile row and tile column.

GET

Request URL Template

http://{hostname}/{service instance}/{zoom:int}/{x:int}/{y:int}.mvt

Request Parameters

Parameter Name Optional or Required Description
zoom Required Specifies the tile zoom level used to get the vector tile, as described in the Slippy Map Tilenames specification.
x Required Specifies the tile column used to get the vector tile, as described in the Slippy Map Tilenames specification.
y Required Specifies the tile row used to get the vector tile, as described in the Slippy Map Tilenames specification.

Sample Request

http://hostname/NetworksVectorTileService/8/70/92.mvt

Sample Response

The response is a vector tile in the MapBox vector tile file format.

Get Tile Errors

Response HTTP Status Code Description
Tile not found. 404 Check the column and row of the tile requested in the query.
Zoom level must be between the {minimum} and {maximum} zoom level. 422 The zoom level specified in the query is not between the minimum and maximum zoom level as defined in the Tile JSON.
