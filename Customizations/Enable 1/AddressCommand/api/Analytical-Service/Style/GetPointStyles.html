GetPointStyles

Returns the named point styles.

GET

Request URL Template

http://{HostName}/{TraceServiceName}/style/pointstyles?pageNo={pageNo}&pageSize={pageSize}&filter={filter}

Sample Response

[
      {
        "Id": "2604",
        "Name": "100 Schematic Point",
        "FontName": "G_POLE",
        "Symbol": "B"
      },
      {
        "Id": "2611",
        "Name": "117 Schematic Point",
        "FontName": "G_POLE",
        "Symbol": "B"
      }
     ]

Remarks

This method supports both pagination and typeahead filtering.

Returns all the available point styles, when called without pagination and filtering parameters.

Returns the list of point styles, in pages honoring the page size when it is called with pagination parameters.

Returns list of named point styles starting with the given filter parameter value, when it is called with filter parameter.

Response contains:

'Id' - unique identifier for the point style.

'Name' - descriptive information that helps in easy identification of FontName.

'FontName' - name of the font used for the style.

'Symbol' - is a single character associated with the feature type.
