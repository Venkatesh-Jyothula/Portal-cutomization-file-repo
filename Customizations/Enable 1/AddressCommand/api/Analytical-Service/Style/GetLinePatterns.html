GetLinePatterns

Returns the named line patterns.

GET

Request URL Template

http://{HostName}/{TraceServiceName}/Styles/linepatterns?pageNo={pageNo}&pageSize={pageSize}&filter={filter}

Remarks

This method supports both pagination and typeahead filtering.

Returns all the line patterns available, when called without any parameters.

Returns the list of line patterns, in pages honoring the page size when it is called with pagination parameters.

Returns list of named line patterns starting with the given filter parameter value, when it is called with filter parameter.

Response contains:

'Id' - unique identifier for the line pattern.

'Name' - descriptive information that helps in easy identification of line pattern.
