GetSearchResults

Returns all the analysis (query or trace) results corresponding to the given result identifier.

Results identifier formats:

Type Format
Query Search.{AMNO}.{QUERYID}
Trace Trace.{TNO}

GET

Request URL Template

http://{HostName}/{TraceServiceName}/search/results/fetch?resultid={resultid}&pageNo={pageNo}&pageSize={pageSize}

Request Parameters

Parameter Name Description Mandatory
resultid Result identifier Y
pageNo Page Number, 1-based.
pageSize Page Size.
Augment Adding new attributes to the result set by providing attribute numbers(ano's) or attribute field names(ComponentName.AttributeFieldName).
Sum Sum of a response parameter or simple arithmetic computation of response fields.
Avg Average of a response parameter or simple arithmetic computation of response fields.
Max Maximum value of a response parameter or simple arithmetic computation of response fields.
Min Minimum value of a response parameter or simple arithmetic computation of response fields.
GroupBy Grouping the response with a response parameters.
OrderBy Ordering the response with a response parameters.
Distinct Distinct value of the response with a response parameter.
Subst Substituting a parameter in the result.
Function Executing an oracle function which always returns a scalar value.

Remarks

This method supports pagination. When pagination parameters are specified, it returns the query results in pages based on requested page number and page size. When no pagination parameters are specified, it returns all of the search results corresponding to the given result Id.

If aggregation parameters are specified, then aggregation is performed on the result set. These requests are included as part of optional parameters. Multiple aggregation parameters will be supported. All the operations performed are added under a new parameter "aggregate". It includes name, field and value of the requested aggregates. Simple arithmetic operations can also be performed on the response fields for aggregation. Supported operators for arithmetic operation are +, -, *, /. The arithmetic expression will be evaluated for each response item and then the resulting aggregation will be performed. Accepted input types for aggregation are attribute numbers and response field names. The corresponding field name for the specified attribute number should be part of the response. Sample allowable inputs: SUM=100, MIN=g3e_fid

For augmentation, accepted input types are attribute number and ComponentName.AttributeFieldName. user can also specify an alias name which is used to display in the result set. The augmented fields can also participate in aggregation or substitution. Multiple augmented fields can be specified using a comma seperator. Sample allowable inputs: augment=100,100@augmentedfield1,componentname.augmentfield2,componentname.augmentfield2@augmentedfield3

Substitution is performed on individual attributes or attributes in specific ranges. First parameter is the attribute parameter that needs to be evaluated, second parameter is the expression that needs to be evaluated upon and the third parameter is the substituted value that is assigned. The switching value will be replaced with the original value in the response. For any response item that do not fall under the expression, the original value for that parameter is retained. Multiple substitution fileds can be provided by using a comma seperator. Supported operators are : =, <>, <, >, >=, <=, OR, AND, NOT LIKE, LIKE, IN. Sample allowable inputs: Subst=G3E_FID,Small,G3E_FID >= 470408 AND G3E_FID <= 470600, G3E_FID,Medium,G3E_CNO = 29 AND G3E_CID = 1

If function parameter is specified, then the input function is executed. The function return value when executed is always a scalar value. Adds a new parameter to the result set with its response as the function return value. The new parameter name is provided as the alias name when specifying the function parameter. When alias name is not provided the function name will be added as the new parameter name. The parameters to the Oracle function will always be G3E_FNO and G3E_FID from the output result set. The resulting value through the execution of this function is always a single value which is displayed as the parameter value.

When input parameters include augmentation, functions, aggregation and substituion, the order of execution is augmentation, functions, substitution, GroupBy/OrderBy/Distinct and then aggregation.
