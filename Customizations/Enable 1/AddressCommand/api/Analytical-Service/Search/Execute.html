Execute

Perform a search and return the results.

POST

Request URL Template

http://{HostName}/{AnalyticalServiceName}/search/execute/{amno}?[Jobs={list of job names} | ActiveJob={job name} | apiVersion={apiVersion}]

Request Parameters

Parameter Name Description
amno G3E_AMNO from the search definition.
pageNo Optional page Number. When pagination parameters are specified, the query results are returned in pages based on the requested page number and page size. Page number 1 is the first page.
pageSize Optional page Size.
ActiveJob Optional job name whose pending edits will participate in the operation.
Jobs Optional comma separated list of jobs whose pending edits will participate in the operation.
apiVersion Analytical service version. Supported versions are 2.0.2012 and above.

Post Body

Post Body Name Description
Parameters Array of search input parameter objects. Each parameter object can be one of: TextValue, DateTimeValue, PickListKey
Parameters[n].ParameterId The ID of the parameter.
Parameters[n].TextValue Search definition takes a text string as input.
Parameters[n].DateTimeValue Search definition takes a date / time as input.
Parameters[n].PickListKey Search definition takes a pick list item as input.
Parameters[n].LongValue Search definition takes an integer number as input.
Parameters[n].DoubleValue Search definition takes a floating point number as input.
Aoi Object returned by the Areas endpoint. Used to pass AOI and/or AOILI to a search definition that requires one as input.
OverrideAoiThreshold Optional. The AoiThreshold is a metadata defined limit for the maximum number of features from an area to use when restricting searches. (See the G3E_GENERALPARAMETER topic in the HxGN NetWorks Core-Admin help). If the AoiOverwriteThreshold metadata parameter is set to -1 (meaning override is possible); and if the current database user has the role associated with G3E_AOIOverwriteThreshold in the G3E_ROLEASSOC_OPTABLE, then this OverrideAoiThreshold POST body parameter controls whether or not the limit will be enforced. When OverrideAoiThreshold is set to false and the AOI contains more possible feature instances than the limit, the search execution will return an error message that denotes how many possible matches were in the area. When this value is set to true, the search execution continues and returns all matching results. The default value is false.
SpatialFilter Specifies a GeoJson Polygon that is used to restrict the search execution results. All of the features in the search result will be restricted to features that are within or touching the specified polygon. Detail features are included if their geographic referencing feature is in the polygon. Polygon is the only geometry type supported for spatial filters. A search request cannot contain both an AOI and a SpatialFilter value. The OverrideAoiThreshold parameter and the associated AOI processing also apply to the area defined by the spatial filter.
MeasureFeatures When specified as true, the search result will be augmented with the length or area measurement of each feature that can be measured. If the search result was restricted by an AOI or spatial filter polygon, then the percentage of the features that fall within the spatial filter area will also be computed. Specifically, the geometry of the features that intersect the spatial boundary will be clipped and measured and the clipped measurement / the original measurement will be reported as a percent value.
MeasureOnCurvedEarth When specified as true, the length or area measurement of each feature will be done using the geographic reference space; otherwise, the measurements will be done on the projection reference space.
FilterSet Optional. Specifies a previous trace or search result set to join against to restrict the feature instances that will be included in the response. The pending edits in a job can also serve as a filter set. The FilterSet property value must match one of the following: (1) Trace.{traceId} (2) Search.{searchId} (3) Job.{jobId} (4) {table}.{column}.{value}

Results

Results Name Always Returned Or Optional Description
G3E_AMNO Always The analysis mapping number for this search. G3E_ANALYSISMAPPING_OPTABLE.G3E_AMNO
ResultId Optional The result id used to call WMS.GetLayer and used to call /search/delete or /search/fetch. The resultId is not set for searches that return no rows.
ResultUserName Always The user facing name of the search results.
DatabaseAlias Always The database service name from tnsnames.ora.
Configuration Always The NetWorks configuration name from the CCM file.
MaxLimitExceeded Always Boolean true or false if the maximum number of records was exceeded.
AoiThresholdExceededMessage Optional This user message is present when the metadata defined AoiThreshold limit has been exceeded and the current user has the necessary user role to override the threshold. Example message: "The number of possible search results from the area of interest, {0}, exceeds the threshold, {1}. Do you want to override the threshold and retrieve all results?" If the user wants to override, the client should resubmit the search execute request with "OverrideAoiThreshold": true added to the POST body of the request.
ComponentField Optional The property name of the component field in the result items. Use this to find the component field value in the results.
ComponentFieldUserName Optional The user facing name of the component field. Use this for the column header in the master results display.
InformationalField Optional The property name of the informational field in the result items. Use this to find the informational field value in the results.
InformationalFieldUserName Optional The user facing name of the first component field. Use this for the column header in the master results display. The metadata for Find Feature and Find Component provides localized names for some of the data columns returned in the result items. The result items array of objects will use the component attribute names and informational attribute names. The corresponding user visible names are provided in the results header for display purposes.
InformationalField Optional The property name of the first informational field in the result items. Use this to find the informational field value in the results.
InformationalFieldUserName Optional The user facing name of the first informational field. Use this for the column header in the master results display.
ComponentField2 Optional The property name of the second component field in the result items. Use this to find the component field value in the results.
ComponentFieldUserName2 Optional The user facing name of the second component field. Use this for the column header in the master results display.
InformationalField2 Optional The property name of the second informational field in the result items. Use this to find the informational field value in the results.
InformationalFieldUserName2 Optional The user facing name of the second informational field. Use this for the column header in the master results display.
Parameters Always The search execute input parameters.
ResultItemsCount Always The count of the number of result items found.
ResultItems Always An array of result items. Properties added by the search service are prefixed with GAO_NET.

Remarks This method supports pagination. When pagination parameters are specified, it returns the query results in pages based on the requested page number and page size. When no pagination parameters are specified, it returns all of the search results corresponding to the given result Id. This method supports API versioning, apiVersion value of 2.0.2012 or later will support long and double parameter values.

The response header will contain the X-Paging-xxx set of header tags (i.e. X-Paging-PageNo, X-Paging-PageSize, X-Paging-PageCount, X-Paging-TotalRecordCount).
