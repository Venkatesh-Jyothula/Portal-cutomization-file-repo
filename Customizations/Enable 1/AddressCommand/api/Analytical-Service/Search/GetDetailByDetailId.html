GetDetailByDetailId

Gets the MBR of a detail given its detail number.

GET

Request URL Template

http://{HostName}/{AnalyticalServiceName}/search/detail/{detailId}[?lsno={lsno}]

Request Parameters

Parameter Name Description
detailId Detail number (typically G3E_DETAILID value).
lsno Legend settings number (typically G3E_LSNO value). Optional. When provided, the searchs filters out detail records with different legend settings number.

    "geographicBoundingBox": {

        "miny": 53.460928420993866,
        "maxx": 12.030478076793822,
        "maxy": 53.460966150550675

Note

If the detail can't be found, the method returns HTTP status code 400 (Bad request) and informational message in the body.
