GetSearches

Gets the list of all search definitions, excluding quicksearch definitions.

GET

Request URL Template

http://{HostName}/{AnalyticalServiceName}/search/searches[?application={application} | apiVersion={apiVersion}]

Request Parameters

Parameter Name Description
application Bit mask for G3E_ANALYSIMAPPING_OPTABLE.G3E_APPLICATION. When not specified, a value of 8 (NetWorks) is used.
apiVersion Analytical service version. Supported versions are 2.0.2012 and above.

Response

Array of SearchMetadataType instances.

SearchMetadataType

Name Type Description
G3E_AMNO number Analysis mapping number
UserName string Analysis mapping name
G3E_ACNO number Analysis category number
CategoryName string Analysis category name
Parameters [SearchParameterType] Array of parameters of the query
IsAoiRequired bool Flag: Is active AOI required?
IsAoiLiRequired bool Flag: Is AOI LI required?

SearchParameterType

Name Type Description
G3E_ANO number Attribute number
ParameterId number Ordinal of the parameter in query. G3E_ORDINAL.
ReferenceOrdinal number Reference ordinal for repeated G3E_ANO values. G3E_REFERENCEORDINAL.
G3E_USERNAME string User name of the search parameter
Type string Data type of the value. Allowed values: Text, PickList, DateTime.
G3E_PNO number Picklist number.
FieldValueFilterAttributes [number] If a field value filter is defined, contains an array of G3E_ANO values required for field value filter. Otherwise null which means that field value filter is not defined.

Remarks If the search definition has IsAoiLiRequired set to true, then the last parameter is a placeholder for the area of interest location identifier's string value. The Post body that is passed to the search/execute/{amno} method must contain an Aoi object definition and its AOILIID property must be non-null.

If the search definition has IsAoiRequired set to true, then the Post body that is passed to the search/execute/{amno} method must contain an Aoi object definition in the JSON (see execute method).

If the search definition has apiVersion parameter set to 2.0.2012 or later, the response attribute parameters will support long and double parameter values.
