GetSearchesByAcno

Gets the list of searches associated with the given search category number.

GET

Request URL Template

http://{HostName}/{AnalyticalServiceName}/search/searches/{acno}[?application={application}| apiVersion={apiVersion}]

Request Parameters

Parameter Name Description
acno Search Category Number for which to get searches.
application Bit mask for G3E_ANALYSIMAPPING_OPTABLE.G3E_APPLICATION. When not specified, a value of 8 (NetWorks) is used.
apiVersion Analytical service version. Supported versions are 2.0.2012 and above.

Sample URL

http://localhost/NetWorksAnalyticalServiceCommProd/Search/Searches/4?apiVersion=2.0.2012
