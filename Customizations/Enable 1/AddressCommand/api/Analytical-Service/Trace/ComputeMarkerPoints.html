ComputeMarkerPoints

Computes the marker location points for an executed trace based on user defined stop criteria.

POST

Request URL Template

http://{HostName}/{TraceServiceName}/Trace/computemarkerpoints

Post Body Parameters

Parameter Name Description Required
tno Trace number of the executed trace. Yes
StopCriteria Input stop criteria. Yes

Sample Request

http://hostname/NetworksAnalyticalservice/Trace/computemarkerpoints

Post Body :

{
    "StopCriteria":25,
    "TraceId":19775
}

Sample Response

{
    "PointX": -8511548.62955291,
    "PointY": 5507937.9876390938,
    "DetailId": 0
}

Remarks

Pre-requisite to execute the API:

A new GAONET_PARAMETER table is introduced which contains the following columns:

Column Name Description
GAO_PNO Maps to G3E_RINO value for the Interface
GAO_KEY Unique identifier for the table, Even though GAO_PNO is unique, it might be null for some entries. Eg: If the Compute Partial Start Value Interface Argument Group Number is null, then the relevant G3E_RINO values will not exist for Stop criteria field name, Cable Value Filed Name and Cumulative Value Field Name.
GAO_TYPE For ComputeMarkerPoints API, it checks for OTDR value
GAO_PARAMETERNAME G3E_USERNAME field of G3E_RELATIONIFACE_OPTABLE
GAO_PARAMETERDESCRIPTION G3E_TYPE field of G3E_RELATIONIFACE_OPTABLE
GAO_PARAMETERVALUE G3E_INTERFACE field of G3E_RELATIONIFACE_OPTABLE
GAO_PARAMETERTYPE Will be the interface argument data type
GAO_EDITDATE Edit Date

Sample values that are stored in the GAONET_PARAMETER table for OTDR:

GAO_PNO GAO_KEY GAO_TYPE GAO_PARAMETERNAME GAO_PARAMETERDESCRIPTION GAO_PARAMETERVALUE GAO_PARAMETERTYPE
1 10 OTDR Compute Marker Location Interface Number 21 4
2 10 OTDR Compute Marker Location Interface Argument Group Number 715001 4
3 10 OTDR Compute Geo Point Interface Number 22 4
4 10 OTDR Compute Geo Point Interface Argument Group Number 715002 4
5 10 OTDR Compute Partial Start Value Interface Number 29 4
6 10 OTDR Compute Partial Start Value Interface Argument Group Number -1 4
7 10 OTDR Stop Criteria Field Name INPUT_STOP_CRITERIA 10
8 10 OTDR Cable Value Field Name STOP_CRITERIA 10
9 10 OTDR Cumulative Value Field Value CUMULATIVE_STOP_CRITERIA 10

Response contains:

'PointX' is the x coordinate of the marker point.

'PointY' is the y coordinate of the marker point.

'DetailId' is the identifier of the detail drawing where the marker point exists.
