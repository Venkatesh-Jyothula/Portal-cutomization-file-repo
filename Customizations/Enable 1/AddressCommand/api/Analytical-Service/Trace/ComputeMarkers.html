ComputeMarkers

Computes marker points for executed cost constraint trace.

POST

Request URL Template

http://{HostName}/{TraceServiceName}/Trace/ComputeMarkers/{tno}[?rpno={rpno}]

Parameters

Parameter Name Description Required
tno TNO returned from previous Execute Trace call Yes
rpno RPNO of requested report. If not provided, the setting is read from service configuration. No

Post Body Parameters

Parameter Name Description Required
MappingId Should be the same mappingId as used in Execute Trace call. Yes
Attributes Required for executing trace. Should contain Step Cost attribute as defined for current trace. Yes

Sample Request

http://hostname/NetworksAnalyticalservice/Trace/ComputeMarkers/1010?rpno=300

Post Body :

{
    "MappingId": "442",
    "Attributes": [{
            "Key": "30500",
            "Value": "13"
        }
    ]
}
