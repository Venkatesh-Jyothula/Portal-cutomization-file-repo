GetTraceParameters

Returns the trace parameters for the given trace mapping identifier.

GET

Request URL Template

http://{HostName}/{TraceServiceName}/Trace/parameters/{TraceMappingID}.

Request Parameters

Parameter Name Description
MappingId Desired mapping identifier as string.

Sample Request

http://hostname/NetworksAnalyticalService/Trace/parameters/559

Sample Response

{
    "TraceId": "320",
    "Description": "Traces cables or wires downstream or upstream from selected start feature and stops based on cumulative distance.",
    "MappingUserName": "OTDR Cumulative Distance Trace",
    "MappingId": "559",
    "Attributes": [{
            "Prompt": "Marker Location",
            "DataType": "7",
            "TraceAttributeNo": "359",
            "IsPickListAttribute": false,
            "AttributeNo": "256010003",
            "Format": "General Number"
        }
    ],
    "PromptForGoal": false,
    "PromptForHint": false,
    "HintIdentifiesFeature": true,
    "GoalFnoCandidates": null,
    "UsePickListKey": true,
    "RequiresPartialValue": true
}

Remarks

Response contains:

'MappingId' - a unique identifier.

'TraceId' - trace instance id for the given mappingId.

'Description' - trace description.

'MappingUserName' - name given to the trace.

'PromptForGoal' - a boolean value depends up on "promptforgoal" column for the given mappingId.

'PromptForHint' - a boolean value depends up on "promptforhint" column for the given mappingId.

'HintIdentifiesFeature' - a boolean value depends up on "HintIdentifiesFeature" column for the given mappingId.

'GoalFnoCandidates' - gives the list of goal features for the given mappingId.

'UsePickListKey' - returns true if picklist is defined for the given mappingId, else false.

'RequiresPartialValue' - returns true if trace requires entry of partial value and related coordinates, otherwise false.

'Attributes' - returns list of attributes defined for the given mappingId.
