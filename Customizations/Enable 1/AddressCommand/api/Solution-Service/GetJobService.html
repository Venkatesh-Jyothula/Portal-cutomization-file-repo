GetJobService

Returns information about the Job service in the configured solution.

GET

Request URL Template

http://{HostName}/NetWorksSolutionService/{DatabaseAlias}/job

Request Parameters

Parameter Name Description
DatabaseAlias The database alias as a string.

Sample Response

[
       {
         "Name": NetWorksJobService,
         "Type": "JobService",
         "Description": "NetWorks Job Service,
         "Configuration: "CONFIG3857",
         "Url": "http://SERVERNAME/NetWorksJobService"
       }
     ]

Remarks

There can be only one Job Service in a solution.
