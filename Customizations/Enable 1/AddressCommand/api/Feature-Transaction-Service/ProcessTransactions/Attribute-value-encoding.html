Attribute value encoding

Attribute data types and their encoding in requests and responses:

string

Encoded as JSON string value.

{ 
  "TEXT": "Example text 1" 
}

number

Encoded as JSON number, with . as decimal separator. Both integer and double values are supported.

{ 
  "LENGTH": 12.56 
}

datetime

Wrapped in a JSON object with single "d" property containing string value in ISO 8601 format.

{ 
  "LAST_CLEANING_DT": { 
    "d": "2020-01-02T15:46:22"
  } 
}

geometry

Wrapped in a JSON object with single "wkt", "networksjson" or "geojson" property which contains a WKT string representation of the geometry, JSON representation of the NetWorks geometry format or GeoJSON respectively.

See Geometry serialization for details.

{
  "G3E_GEOMETRY": {
    "wkt": "POINT M (4501991.49 5925480.29 1570000)"
  }
}

{
  "G3E_GEOMETRY": {
    "networksjson": {
      "type": "OrientedPoint",
      "origin": [4501991.49, 5925480.29, 3],
      "orientation": [0, 1, 0]
  }
}

file

Wrapped in a JSON object with single "f" property which contains the relative path to the file within the transaction.

Note

Feature Transaction Service performs transformation of the incoming value (see Hyperlink mapping, but does not copy or move the physical file. This is done by Work Service as post-processing after the ProcessTransactions completes.

{
  "ATTACHMENT_HL": {
    "f": "photo1.jpg"
  }
}

binary

Wrapped in a JSON object with single "b" property containing string value with Base64 encoding.

{
  "INTERFACE": {
    "b": "dGVzdA=="
  }
}
