Hyperlink mapping

File references in CreateComponent, UpdateComponent transactions are transformed before inserting or updating data in database. The purpose of this step is to transform the relative path to a file within transaction to attribute value and also to a physical path (which may be different). The transformed physical path is returned in response of the ProcessTransactions request in links property of the attribute.

Hyperlink transformation uses the following configuration parameters in table NWG_GENERALPARAMETER:

  • HyperlinkFilter
  • HyperlinkPathTemplate
  • HyperlinkValueTemplate

All file references ("f" attributes), which pass regular expression defined in HyperlinkFilter are transformed. If HyperlinkFilter is empty, all files references are processed.

HyperlinkValueTemplate is the template for attribute value. If not specified, the source value is copied without modification.

Secondary link is constructed using HyperlinkPathTemplate. This value is not stored in database. It is returned in the response to the caller in the links property of the transaction. The caller is expected to use this value to perform a physical file operation with the file.

Hyperlink templates are strings which may contain placeholders. Placeholders are enclosed in curly brackets {}. Each placeholder has a source, optional format string separated by : and zero or more processing instructions, separated by |.

Placeholder format:

{source}
{source:format}
{source|processing}
{source:format|processing1|processing2|…|processingN}

Available placeholders

Source Data type Processing
value string Original value of the hyperlink.
fid number G3E_FID of the current feature
fno number G3E_FNO of the current feature
cid number G3E_FID of the current component instance
cno number G3E_FNO of the current component instance
date datetime Current date and time.
job string Current job identifier.
uid string Unique identifier, 32 character long.

Formatting

For formatting numeric values, see .NET numeric format strings (documentation). For formatting date and time values, see .NET date and time format strings (documentation).

Processing instructions

Instruction Processing
substr(start,length) Substring, starting at index start (0-based), length characters long.
file Returns file name without path.
filename Returns file name without path and extension.
fileext Returns file extension.
filepath Returns file path.

Example 1 – HyperlinkFilter

Regular expression to match any file path except for those starting with http://, https:// or file://

^(?!(?:file|https?)[:]\/\/.*$).*

Example 2 – HyperlinkValueTemplate or HyperlinkPathTemplate

%ATTACHMENTS%\{date:yyyy}\{date:MM}\{uid|substr(0,2)}\{uid|substr(2,2)}\{uid}\{fid:0000000000}-{fno}\{cno}-{cid}\{value|file}

With context values:

  • file reference attachment1.pdf
  • date 2020-01-02
  • unique id 01234567890123456789012345678901
  • FNO,FID,CNO,CID = 999,25252,456,1

Is translated to:

%ATTACHMENTS%\2020\01\01\23\01234567890123456789012345678901/0000025252-999/456-1/attachment1.pdf
