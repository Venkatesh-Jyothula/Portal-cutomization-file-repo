Vector Tile Service

The Vector Tile Service provides a RESTful API for retrieving and publishing MapBox vector tiles.

Retrieve Vector Tiles

Method Uri Description
GET /{zoom}/{x}/{y}.mvt Returns the vector tile in the MapBox vector tile file format using the specified zoom level, tile row and tile column.
GET /Tiles.json Returns the TileJSON metadata.
GET /Style.json Returns the MapBox JSON style specification document.
