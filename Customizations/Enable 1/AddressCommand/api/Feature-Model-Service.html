Feature Model Service

The HxGN NetWorks Feature Model Service provides API for querying HxGN NetWorks Core data and metadata and editing HxGN NetWorks Core features.

Get Feature Data

Method Uri Description
GET /data/{featureName}?[{oDataOptions}][& BBOX={left,bottom,right,top}][&FilterSet={filterSetId}][&MeasureFeatures={true or false}][&MeasureOnCurvedEarth={true or false}][& Jobs={list of job names} or ActiveJob={job name} ] Returns the requested feature data for the specified feature type that matches the optional OData filter options and bounding box.
GET /data/{featureName}/{fid}?[{oDataOptions}][& Jobs={list of job names} or ActiveJob={job name} ] Returns the requested feature data for the specified feature instance that matches the specified G3E_FID value.
GET /data/{featureName}/{fid}/{componentName}[/{cid}]?[{oDataOptions}][& Jobs={list of job names} or ActiveJob={job name} ] Returns the requested component for the specified feature instance that matches the specified G3E_FID value, and G3E_CID if component is repeating.
GET /data/{featureName}/{fid}/{componentName}[/{cid}]/{attributeName}[/$value]?[& Jobs={list of job names} or ActiveJob={job name} ] Returns the requested component attribute for the specified feature instance that matches the specified G3E_FID value, and G3E_CID if component is repeating.

Edit Feature Data

Method Uri Description
POST /data/{featureName}?[{oDataOptions}][& ActiveJob={job name} ] Returns a new instance of the specified feature type.
PUT /data/{featureName}/{fid}?[{oDataOptions}][& ActiveJob={job name} ] Updates the specified feature instance that matches the specified G3E_FID value and returns the requested feature information.
DELETE /data/{featureName}/{fid}?[ ActiveJob={job name}] Deletes the specified feature instance.
DELETE /data/{featureName}/{fid}/{componentName}/{cid}?[ ActiveJob={job name} ] Deletes the specified component instance from the specified feature.

Get Model Metadata for Features

Method Uri Description
GET /metadata/modelfeatures[/{filter}] Returns metadata about the feature types in the published feature model.
GET /metadata/modelfeature/{fno} Returns metadata about the specific feature type.

Get General Metadata for Features

Method Uri Description
GET /metadata/features[/{filter}] Returns metadata about the HxGN NetWorks Core feature types.
GET /metadata/feature/{fno} Returns metadata about the specific HxGN NetWorks Core feature type.
GET /metadata/component/{cno} Returns metadata about the specific HxGN NetWorks Core component type.
GET /metadata/relationship/{rno} Returns metadata about the specific HxGN NetWorks Core relationship type.
GET /metadata/attribute/{ano} Returns metadata about the specific HxGN NetWorks Core attribute type.
