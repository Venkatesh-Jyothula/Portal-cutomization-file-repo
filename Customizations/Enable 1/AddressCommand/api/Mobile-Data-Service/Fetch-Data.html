Fetch Data

Downloads the published data file(s) for the completed publish task.

GET

Request URL Template

http://{hostname}/{service instance}/fetch/data/{taskid}

Request Parameters

Parameter Name Optional or Required Description
taskid Required Specifies the Id of the completed publish task.

Sample Request

http://hostname/NetWorksMobileDataService/fetch/data/{taskid}

Response

The published data file(s) for the given task are downloaded with taskid as file name. The downloaded file will be either geopackage file or zip file which contains below combination of files according to post body parameters mentioned in Publish process.
