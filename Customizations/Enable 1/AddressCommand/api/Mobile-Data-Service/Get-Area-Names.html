Get Area Names

Gets the list of all area of interests (AOIs) configured in the database.

GET

Request URL Template

http://{hostname}/{service instance}/area/names

Sample Request

http://hostname/NetWorksMobileDataService/area/names

A JSON response is returned containing the list of AOIs.
