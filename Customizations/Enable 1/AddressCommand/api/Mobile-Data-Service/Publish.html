Publish

Initiates a task to bulk publish vector tiles and HxGN NetWorks Core data and metadata for given filter polygons.

The Id from the returned payload can be used to check status of the publish task or to fetch data once the publish is complete.

POST

Request URL Template

http://{hostname}/{service instance}/publish/start

Post Body Templates

{
    "RefreshCache": true,
    "PublishMaxZoomLevel": 19,
    "PublishData": true,
    "PublishTiles": true,
    "PublishDetails": true,
    "IncludeStyles": false,
    "IncludeGlyphs": false,
    "PackageFormat": "gpkg",
    "Polygons": [
        {
            "type": "Polygon",
            "coordinates": [
                ...
            ]
        }
    ]
}

Post Body Parameters

A list of validation errors is returned for the specified job. Job has to have pending edits. PageNo and pageSize are used for paging the result.

Parameter Name Optional or Required Description
RefreshCache Optional A boolean value to recreate and overwrite the existing vector tiles regardless of the expiry. Default value is false.
PublishMaxZoomLevel Optional Specifies the maximum zoom level to publish vector tiles for. Value should be less than or equal to configured maximum zoom level. Default value is the maximum zoom level configured when deploying the service.
PublishData Optional A boolean value that indicates whether to publish attribute data and metadata. Default value is true. Details data (i.e., attributes, traces, searches, dialogs metadata, and its corresponding data) published if the PublishDetails value is true.
PublishTiles Optional A boolean value that indicates whether to publish vector tiles. Default value is true.
PublishDetails Optional A boolean value that indicates whether to publish details. Default value is false.
IncludeStyles Optional A boolean value that indicates whether to include styles. Default value is false. Details styles are included if the PublishDetails value is true.
IncludeGlyphs Optional A boolean value that indicates whether to include glyphs. Default value is false.
PackageFormat Optional Specifies the package format either 'gpkg' or 'file'. If the PackageFormat is not defined, the tiles and details are published into disk only but do not fetch them and put it in either geopackage or file.
Polygons Required Polygons are used as spatial filters when publishing vector tiles and attribute data.
