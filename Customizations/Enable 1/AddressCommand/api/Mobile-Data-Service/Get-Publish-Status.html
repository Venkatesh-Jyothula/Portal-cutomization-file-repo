Get Publish Status

Returns the current status of the given publish task.

GET

Request URL Template

http://{hostname}/{service instance}/publish/status/{taskid}

Request Parameters

Parameter Name Optional or Required Description
taskid Required Specifies the Id of the initiated publish task.

Sample Request

http://hostname/NetWorksMobileDataService/publish/status/{taskid}

Sample Response

A JSON response is returned that contains the status of the given publish task.
