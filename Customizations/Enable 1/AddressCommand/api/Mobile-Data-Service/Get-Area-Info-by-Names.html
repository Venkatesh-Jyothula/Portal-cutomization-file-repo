Get Area Info by Names

Gets the information for the given area of interests (AOIs).

GET

Request URL Template

http://{hostname}/{service instance}/area/{names}

Request Parameters

Parameter Name Optional or Required Description
names Required Specifies a comma separated list of area of interest (AOI) names.

Sample Request

http://hostname/NetWorksMobileDataService/area/SWITCHING CENTRE: PRINCE,SWITCHING CENTRE: KING
