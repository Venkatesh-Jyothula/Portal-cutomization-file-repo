Get Region Info by Names

Gets the information for the given regions.

GET

Request URL Template

http://{hostname}/{service instance}/region/{names}

Request Parameters

Parameter Name Optional or Required Description
names Required Specifies a comma separated list of region names.

Sample Request

http://hostname/NetWorksMobileDataService/region/IRTNON12,IRSLON37

Sample Response

A JSON response is returned containing the information for the given regions.
