Coordinate System Service

Coordinate System Service provides methods for getting information on coordinate systems and transformation of coordinates between coordinate systems.

Information

Method Uri Description
GET /configuration/{configuration}/names Get list of coordinate system names defined within a configuration.
GET /configuration/{configuration}/list Get list of coordinate systems defined within a connected configuration along with their parameters.
GET /configuration/{configuration}/info/configuration Get parameters of coordinate system of selected NetWorks configuration.
GET /configuration/{configuration}/info/database Get parameters of database coordinate system underlying selected NetWorks configuration.
GET /configuration/{configuration}/info Get parameters of specified coordinate system.

Coordinate transformation (configuration specific)

Method Uri Description
GET /configuration/{configuration}/configtodb Transform coordinates of 1 or 2 points from configuration to database coordinate system.
POST /configuration/{configuration}/configtodb Transform coordinate array from configuration to database coordinate system.
GET /configuration/{configuration}/configtogeog Transform coordinates of 1 or 2 points from configuration to geographic coordinate system.
POST /configuration/{configuration}/configtogeog Transform coordinate array from configuration to database coordinate system.
GET /configuration/{configuration}/dbtoconfig Transform coordinates of 1 or 2 points from database to configuration coordinate system.
POST /configuration/{configuration}/dbtoconfig Transform coordinate array from database to configuration coordinate system.
GET /configuration/{configuration}/dbtogeog Transform coordinates of 1 or 2 points from database to geographic coordinate system.
POST /configuration/{configuration}/dbtogeog Transform coordinate array from database to geographic coordinate system.
GET /configuration/{configuration}/geogtoconfig Transform coordinates of 1 or 2 points from geographic to configuration coordinate system.
POST /configuration/{configuration}/geogtoconfig Transform coordinate array from geographic to configuration coordinate system.
GET /configuration/{configuration}/geogtodb Transform coordinates of 1 or 2 points from geographic to database coordinate system.
POST /configuration/{configuration}/geogtodb Transform coordinate array from geographic to database coordinate system.

Coordinate transformation (generic)

Method Uri Description
GET /configuration/{configuration}/transform Transform coordinates of 1 or 2 points from source to destination coordinate system.
POST /configuration/{configuration}/transform Transform coordinate array from source to destination coordinate system.
