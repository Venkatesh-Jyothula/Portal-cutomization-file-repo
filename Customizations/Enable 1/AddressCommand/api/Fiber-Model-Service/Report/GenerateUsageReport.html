GenerateUsageReport

Generates the fiber usage report that describes the usage of a fiber device or conductor.

The output report shows the percentage and actual count of fibers that are In Use, Available, and Unlit.

  • In Use means that the fiber has a light source from a device like a Fiber Patch Panel and is terminated at a customer (for example, Optical Network Unit).
  • Available means the fiber has a light source, but is not terminated at any customer downstream.
  • Unlit means the fiber has no light source.

POST

Request URL Template

http://{hostname}/{service instance}/Fiber/Report/GenerateUsageReport?Jobs={list of job names}&ActiveJob={job name}

Request Parameters

Parameter Name Optional or Required Description
ActiveJob Optional Job name whose pending edits will participate in the operation.
Jobs Optional Comma separated list of jobs whose pending edits will participate in the operation.

Post Body Templates

{
	          "StartFeatureFno":7200,
	          "StartFeatureFid":29758,
	          "Low":1,
	          "High":10
          }

Post Body

Post Body Name Description
StartFeatureFno Fiber feature number of the starting conductor or device.
StartFeatureFid Fiber feature identitifier of the starting conductor or device.
Low Start device port or conductor strand ordinal.
High End device port or conductor strand ordinal.

Sample Request

http://hostname/NetworksFiberModelService/Fiber/Report/GenerateuUsageReport
