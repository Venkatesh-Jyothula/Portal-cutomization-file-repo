GeneratePathReport

Generates the fiber path report that describes the physical connections along a trace, given a starting fiber device port or conductor strand.

POST

Request URL Template

http://{hostname}/{service instance}/Fiber/Report/GeneratePathReport?Jobs={list of job names}&ActiveJob={job name}

Request Parameters

Parameter Name Optional or Required Description
ActiveJob Optional Job name whose pending edits will participate in the operation.
Jobs Optional Comma separated list of jobs whose pending edits will participate in the operation.

Post Body Templates

{
	          "StartFeatureFno":7200,
	          "StartFeatureFid":1552,
	          "Low":1,
	          "High":1,
	          "WaveLength":1550
          }

Post Body

Post Body Name Description
StartFeatureFno Fiber feature number of the starting conductor or device.
StartFeatureFid Fiber feature identitifier of the starting conductor or device.
Low Start device port or conductor strand ordinal.
High End device port or conductor strand ordinal.
OtdrLength OTDR length stop criterion value. The marker location computed is along the conductor on which the cumulative length measured is greater than or equal to the stop criterion.
OtdrLoss OTDR loss stop criterion value. The marker location computed is along the conductor on which the cumulative loss measured is greater than or equal to the stop criterion.
WaveLength Wavelength attenuation value. The loss measured is calculated based on the wavelength specified.

Sample Request

http://hostname/NetworksFiberModelService/Fiber/Report/GeneratePathReport

Sample Post Body

{
	          "StartFeatureFno":7200,
	          "StartFeatureFid":1552,
	          "Low":1,
	          "High":1,
	          "WaveLength":1550
          }
