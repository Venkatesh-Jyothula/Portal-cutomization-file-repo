SpliceConnections

Returns splice connections for a given splice bearing fiber feature along with the details of the connected or owned fiber features.

  • The splice connections returned includes the splice connection attributes.
  • The device ports or conductor strands returned indicates the following status:
  • Connected or Disconnected.
  • Groove Assigned or Unassigned.
  • Only the containers connected to the splice bearing feature are returned for a given conductor.

GET

Request URL Template

http://{hostname}/{service instance}/Fiber/SpliceConnections/{Fno}/{Fid}?Jobs={list of job names}&ActiveJob={job name}

Request Parameters

Parameter Name Optional or Required Description
Fno Required Feature number of the splice bearing fiber feature.
Fid Required Feature identifier of the splice bearing fiber feature.
ActiveJob Optional Job name whose pending edits will participate in the operation.
Jobs Optional Comma separated list of jobs whose pending edits will participate in the operation.

http://hostname/NetworksFiberModelService/Fiber/SpliceConnections/11800/7251

Optional Parameter

An optional filter parameter will filter the results thereby reducing the returned payload. Use comma delimited string as the filter value (example: "connections,from") when applying more than one filter type.

  • Connections - Returns splice connections data excluding all relationship data.
  • Children - Returns child relationship data excluding all other relationship and splice connections data.
  • From - Returns the From fiber feature data in a node-ordered connectivity relationship excluding all other relationship and splice connections data.
  • To - Returns the To fiber feature data in a node-ordered connectivity relationship excluding all other relationship and splice connections data.
  • ExcludeAttributes - Excludes all attribute data associated with splice connections, bundles, strands, port groups and ports.
