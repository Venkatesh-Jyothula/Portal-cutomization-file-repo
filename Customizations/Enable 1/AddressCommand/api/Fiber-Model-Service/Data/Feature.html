Feature

Returns feature data for a given fiber feature instance.

GET

Request URL Template

http://{hostname}/{service instance}/Fiber/Feature/{Fno}/{Fid}/{Filter}?Jobs={list of job names}&ActiveJob={job name}

Request Parameters

Parameter Name Optional or Required Description
Fno Required Fiber feature number.
Fid Required Fiber feature identifier.
Filter Optional Data filter.
ActiveJob Optional Job name whose pending edits will participate in the operation.
Jobs Optional Comma separated list of jobs whose pending edits will participate in the operation.

Sample Request

http://hostname/NetworksFiberModelService/Fiber/Feature/7200/21

Optional Parameter

An optional filter parameter will filter the results only to the given feature number. Use comma delimited string as the filter value (example: "basic,material") when applying more than one filter type.

  • Basic - Returns basic information of the given Fiber feature.
  • Material - Returns material data like bundles, strands, port groups and ports of the given Fiber feature.
  • SpliceConnections - Returns the splice connections data for a given splice bearing Fiber feature.
  • Parent - Returns parent relationship of the given Fiber feature.
  • Child - Returns child relationship of the given Fiber feature.
  • Connectivity - Returns the node-edge or node-ordered connectivity relationship of the given Fiber feature.
  • ContainedBy - Returns the contained by relationship of the given Fiber feature.
  • Container - Returns the container relationship of the given Fiber feature.
  • Relationship - Returns all relationship of the given Fiber feature.
  • All - Returns all the information (basic, material, relationship and splice connections) of the given Fiber feature.
