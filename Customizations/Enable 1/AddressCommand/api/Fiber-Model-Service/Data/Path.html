Path

Returns the path for a given fiber conductor, device, link or channel. This API only works if Path Extensions is part of the model.

GET

Request URL Template

http://{hostname}/{service instance}/Fiber/Path/{Fno}/{Fid}?Jobs={list of job names}&ActiveJob={job name}

Request Parameters

Parameter Name Optional or Required Description
Fno Required Fiber feature number for conductor, device, link or channel.
Fid Required Fiber feature identifier for the conductor, device, link or channel.
ActiveJob Optional Job name whose pending edits will participate in the operation.
Jobs Optional Comma separated list of jobs whose pending edits will participate in the operation.

Sample Request

http://hostname/NetworksFiberModelService/Fiber/Path/7200/52409
