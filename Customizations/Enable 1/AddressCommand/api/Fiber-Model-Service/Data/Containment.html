Containment

Returns the fiber inner duct connections for a given fiber feature.

The fiber inner ducts returned indicates the following status:

  • Cut or Straight Through.
  • Coupled or Not Coupled.

GET

Request URL Template

http://{hostname}/{service instance}/Fiber/Containment/{Fno}/{Fid}?Jobs={list of job names}&ActiveJob={job name}

Request Parameters

Parameter Name Optional or Required Description
Fno Required Feature number of the fiber infrastructure feature.
Fid Required Feature identifier of the fiber infrastructure feature.
ActiveJob Optional Job name whose pending edits will participate in the operation.
Jobs Optional Comma separated list of jobs whose pending edits will participate in the operation.

Sample Request

http://hostname/NetworksFiberModelService/Fiber/Containment/4200/65
