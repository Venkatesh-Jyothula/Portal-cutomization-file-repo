GetRelationshipsTypes

Returns relationship metadata for a feature class.

Request

Method

GET

URL Template

/metadata/relationships/feature/{fno}[?type={type}]

Path variables

Name Type Mandatory Description
{fno} Integer Y G3E_FNO

Query params

Name Type Mandatory Description
{type} String Comma-separated list of type values. When not present, all types are retrieved. Allowed values: ownership, many-ownership, node-edge, node-ordered.

Response

Serialized rows from G3E_RELATIONSIPS_OPTABLE and configured relationship metadata tables.

Example

Example Request

http://machinename/fds/metadata/relationships/feature/300
