GetJobDefinition

Returns content of metadata table G3E_JOBDEFINITION_OPTABLE, G3E_COMMONJOBCLASS_OPTABLE and G3E_FEATUREJOBCLASS_OPTABLE.

Request

Method

GET

URL Template

/metadata/jobs/definition

Parameters

None.

Response

Serialized rows from G3E_JOBDEFINITION_OPTABLE, G3E_COMMONJOBCLASS_OPTABLE and G3E_FEATUREJOBCLASS_OPTABLE

Example

Example Request

http://machinename/fds/metadata/jobs/definition
