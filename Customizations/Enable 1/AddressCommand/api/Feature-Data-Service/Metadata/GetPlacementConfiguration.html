GetPlacementConfiguration

Returns content of metadata tables G3E_CONFIGPLACEMENT_OPTABLE for given G3E_PCNO and relevant rows from G3E_COMPCONFIGURATION_OPTABLE for G3E_CCNO values from G3E_CONFIGPLACEMENT_OPTABLE.

Request

Method

GET

URL Template

/metadata/placement/configuration/{pcno}

Path variables

Name Type Mandatory Description
{pcno} Integer Y G3E_PCNO

Response

Serialized rows from G3E_CONFIGPLACEMENT_OPTABLE and G3E_COMPCONFIGURATION_OPTABLE.

Example

Example Request

http://machinename/fds/metadata/placement/configuration/100
