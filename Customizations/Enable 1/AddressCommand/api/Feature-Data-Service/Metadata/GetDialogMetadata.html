GetDialogMetadata

Returns content of metadata tables G3E_DIALOGS_OPTABLE for given G3E_FNO and G3E_TYPE.

Request

Method

GET

URL Template

/metadata/dialog/tabs/{fno}?type={type}[&attributes={attributes}]

Path variables

Name Type Mandatory Description
{fno} Integer Y G3E_FNO. 0 can be passed in to retrieve dialog tabs for FK queries.

Query params

Name Type Mandatory Description
{type} String Y G3E_TYPE
{attributes} Integer Flag: 1=include dialog tab attribute metadata in response. Other values: attributes are not included. Default is 1.

Response

Serialized rows from G3E_DIALOGS_OPTABLE and G3E_DIALOGATTRIBUTES_OPTABLE.

Example

Example Request

http://machinename/fds/metadata/dialog/tabs/100?type=Edit&attributes=1
