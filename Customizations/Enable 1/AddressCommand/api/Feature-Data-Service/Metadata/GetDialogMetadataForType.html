GetDialogMetadataForType

Returns content of metadata tables G3E_DIALOGS_OPTABLE for given G3E_TYPE.

Request

Method

GET

URL Template

/metadata/dialog/tabs?type={type}[&attributes={attributes}]

Query params

Name Type Mandatory Description
{type} String Y G3E_TYPE
{attributes} Integer Flag: 1=include dialog tab attribute metadata in response. Other values: attributes are not included. Default is 1.

Response

Serialized rows from G3E_DIALOGS_OPTABLE and G3E_DIALOGATTRIBUTES_OPTABLE.

Example

Example Request

http://machinename/fds/metadata/dialog/tabs?type=Test&attributes=1
