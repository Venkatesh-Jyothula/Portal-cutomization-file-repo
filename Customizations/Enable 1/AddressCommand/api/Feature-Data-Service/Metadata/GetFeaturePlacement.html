GetFeaturePlacement

Returns content of metadata table G3E_FEATUREPLACEMENT_OPTABLE for given G3E_FNO and relevant rows from G3E_COMPCONFIGURATION_OPTABLE for G3E_CCNO values from G3E_FEATUREPLACEMENT_OPTABLE.

Request

Method

GET

URL Template

/metadata/placement/feature/{fno}

Path variables

Name Type Mandatory Description
{fno} Integer Y G3E_FNO

Response

Serialized rows from G3E_FEATUREPLACEMENT_OPTABLE and relevant rows from G3E_COMPCONFIGURATION_OPTABLE for G3E_CCNO values from G3E_FEATUREPLACEMENT_OPTABLE. Interface arguments are deserialized to JSON arrays and objects.

Example

Example Request

http://machinename/fds/metadata/placement/feature/100
