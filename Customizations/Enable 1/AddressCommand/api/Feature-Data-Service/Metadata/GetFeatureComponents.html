GetFeatureComponents

Returns content of metadata table G3E_FEATURECOMPS_OPTABLE for given G3E_FNO and relevant rows from G3E_COMPONENTINFO_OPTABLE and G3E_ATTRIBUTEINFO_OPTABLE.

Request

Method

GET

URL Template

/metadata/feature/{fno}/components

Path variables

Name Type Mandatory Description
{fno} Integer Y G3E_FNO

Response

Serialized rows from G3E_FEATURECOMPS_OPTABLE, G3E_FEATUREPLACEMENT_OPTABLE, with added attribute data type information.

Example

Example Request

http://machinename/fds/metadata/feature/100/components
