GetLabelRule

Returns content of metadata table G3E_LABELFILTERS_OPTABLE for given G3E_LRNO. Rows in response are ordered by G3E_FILTERORDINAL.

Request

Method

GET

URL Template

/metadata/label/rule/{lrno}

Path variables

Name Type Mandatory Description
{lrno} String Y Comma separated list of G3E_LRNO values.

Response

Serialized rows from G3E_LABELFILTERS_OPTABLE.

Example

Example Request

http://machinename/fds/metadata/label/rule/1000,1100

Example Response

{
  "labelrule": [
    {
      "lrno": 32308,
      "rule": "Ele-Station-Norm Label - Inventory",
      "filterordinal": 9999,
      "lfno": 323089999,
      "username": "Ele-Station-Norm Label - Inventory - 9999",
      "content": "[TYPE_0009]"
    }
  ]
}
