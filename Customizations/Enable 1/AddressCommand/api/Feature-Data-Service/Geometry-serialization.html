Geometry serialization

Multiple geometry formats are supported in the interfaces:

  • NetWorks geometry format JSON based serialization of the IGTGeometry-like format, which supports all types of geometry.

  • WKT String-based format.

  • GeoJSON JSON-based serialization format, limited to basic types Point, LineString and Polygon. This format does not support features like Arc and CompositePolyline/Polygon geometries.

In JSON, geometries are always serialized as JSON objects. The type of the enclosed geometry is determined from the property name of the object:

Property Format
networksjson NetWorks geometry format
wkt WKT
geojson GeoJSON

Examples

NetWorks JSON geometry format

{
  "networksjson": {
    "type": "OrientedPoint",
    "origin": [1, 2, 3],
    "orientation": [1, 1, 0]
  }
}

WKT

{
    "wkt": "LINESTRING(4502788 5925546, 4502798 5925546)"
}

GeoJSON

{
  "geojson": {
    "type": "Point",
    "coordinates": [1, 2, 3]
  }
}
