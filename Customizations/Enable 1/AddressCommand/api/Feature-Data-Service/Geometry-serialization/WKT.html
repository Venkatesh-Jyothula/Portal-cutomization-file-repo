WKT

Serialization in JSON

Geometries are serialized to WKT strings wrapped in a JSON object with a single wkt property:

{
  "wkt": "POINT (241791.888738 485831.672920)"
}

Supported geometry types

Geometry type WKT Notes
Point POINT
OrientedPoint POINT M
POINT ZM		 Orientation vector is stored in the M dimension
TextPoint POINT M
POINT ZM		 Orientation vector is stored in the M dimension
Polyline LINESTRING
Polygon POLYGON
CompositePolyline LINESTRING
COMPOUNDCURVE
CompositePolygon POLYGON
CURVEPOLYGON
Boundary POLYGON
CURVEPOLYGON

3D versions of the geometries use the Z layout specifier (e.g. LINESTRING Z(1 2 3, 4 5 6)).

Point

Native WKT Point without orientation.

Example

{
  "wkt": "POINT (241791.888738 485831.672920)"
}

OrientedPoint

Used of point symbol and text geometries. Orientation vector is stored in the M dimension using the following formula:

M = (Azimuth * 1000000) + (Elevation / 10)

Azimuth is angle in radians in the XY plane. Vector (1,0) has azimuth of 0, positive values are counterclockwise. Elevation is the angle in radians between the XY plane and the vector, with positive values towards positive Z values. Elevation of 0 is a vector on the XY plane, e.g. (1,0,0). The allowed values are between 0 and π/2 (positive elevation) and 2π and 2π-π/2 (negative elevation + 2π, to avoid negative values).

The result M is a number whose integer part is the azimuth in the XY plane multiplied by 1000000. The decimal part is the elevation in the Z axis divided by 10, to account for all numbers in the 0-2π range.

Vector Azimuth Elevation M
(1,0,0) 0 0 0
(0,1,0) 1.570796 0 1570796
(0,-1,0) -1.570796 0 -1570797
(0.7071068, 0.7071068,0) 0.785398 0 785398
(0.5, 0.5, 0.7071068) 0.785398 0.785398 785398.0785398
(0,0,1) 0 1.570796 0.1570796
(0,0,-1) 0 1.570796 -0.1570796

For reference see Spherical coordinate system on Wikipedia.

The semantics of the orientation follow G/Technology logic. The vector is rotated 90 degrees clockwise from the upright position of the symbol. For symbol geometry to be rendered horizontally (i.e. text or symbol "sits" on the unit vector line), vector (1,0,0) should be used.

Example 2D

{
  "wkt": "POINT M(241791.888738 485831.672920 1570796.0)"
}

Example 3D

{
  "wkt": "POINT ZM(241791.888738 485831.672920 123.345 1550000.066)"
}

TextPoint

As OrientedPoint. The difference to OrientedPoint is semantic. TextPoint is used to display labels. Alignment is stored as a part of the component data outside of the geometry. Rotation vector is only 2D.

Polyline

String of vertices encoded as WKT LINESTRING.

Example

{
  "wkt": "LINESTRING (241790.888738 485830.672920, 241785.672213 485832.860495, 241747.978613 485851.202470)"
}

Polygon

One or more rings of vertices. The first ring is the outer ring, the other are holes. WKT POLYGON geometry can map to G/Technology Polygon, CompositePolygon if it contains only one ring. If there are multiple rings, it always maps to Boundary geometry.

Example

{
  "wkt": "POLYGON ((4502009.984 5925469.015, 4502009.03 5925467.513, 4502011.735, 5925467.513, 4502009.984, 5925469.015))"
}

CompositePolyline

Polyline composed of linestring and circular arc segments. Encoded as WKT COMPOUNDCURVE.

Note This type of geometry is supported by the server workflows, but not for placement and editing in the interactive clients.

Example

{
  "wkt": "COMPOUNDCURVE Z(CIRCULARSTRING (0 0 0,1 1 0,2 0 0),(2 0 0,6 6 0),(6 6 0,5 5 0))"
}

CompositePolygon

Polygon composed of linestring and circular arc segments. Encoded as WKT CURVEPOLYGON.

Note

This type of geometry is supported by the server workflows, but not for placement and editing in the interactive clients.

Example

{
  "wkt": "CURVEPOLYGON Z(COMPOUNDCURVE (CIRCULARSTRING (0 0 0,1 1 0,2 0 0),(2 0 0,6 6 0),(6 6 0,5 5 0)))"
}

Boundary

As Polygon and CompositePolygon, with multiple inner rings.

Example

{
  "wkt": "POLYGON ((4502009.984 5925469.015, 4502009.03 5925467.513, 4502011.735 5925467.513, 4502009.984 5925469.015), (4502019.984 5925469.015, 4502029.03 5925467.513, 4502031.735 5925467.513))"
}

Example 2

{
  "wkt": "CURVEPOLYGON Z(COMPOUNDCURVE (CIRCULARSTRING (0 0 0,1 1 0,2 0 0),(2 0 0,6 6 0),(6 6 0,5 5 0)),COMPOUNDCURVE (CIRCULARSTRING (0 0 0,1 1 0,2 0 0),(2 0 0,6 6 0),(6 6 0,5 5 0)))"
}
