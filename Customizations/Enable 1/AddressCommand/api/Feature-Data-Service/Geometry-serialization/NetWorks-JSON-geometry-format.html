NetWorks JSON geometry format

The NetWorks geometry format uses object-model approach. It uses the set of geometry primitives used by NetWorks Core.

Serialization in JSON

Geometries are serialized to WKT strings wrapped in a JSON object with a single networksjson property, which contains a JSON object. The first property of the geometry JSON object is always type.

{
  "networksjson": {
    "type": "OrientedPoint",
    "origin": [1, 2, 3],
    "orientation": [1, 1, 0]
  }
}

Coordinate

Array of ordinates. The array is expected to have 2 or 3 members ([X, Y] or [X, Y, Z]). Other members beyond Z are ignored. If Z is missing, it is assumed to be 0.

OrientedPoint

Point with orientation vector (unit vector).

Name Type Mandatory Description
type string Y Constant OrientedPoint
origin Coordinate Y Position
orientation Coordinate Orientation unit vector.

Example

{
    "type": "OrientedPoint",
    "origin": [1, 2, 3],
    "orientation": [1, 1, 0]
}

TextPoint

Point with orientation vector (unit vector), text and alignment. This type is not used to represent label geometries.

Name Type Mandatory Description
type String Y Constant TextPoint
origin Coordinate Y Position
rotation double Orientation angle.
text String Label
alignment integer Alignment (see Networks Core constants for alignment).

Example

{
    "type": "TextPoint",
    "origin": [1, 2, 3],
    "rotation": 1.57,
    "text": "text",
    "alignment": 5
}

Polyline

Linear sequence of points.

Name Type Mandatory Description
type string Y Constant Polyline
points Array of Coordinate Y Points

Example

{
    "type": "Polyline",
    "points": [
        [ 1, 2, 3 ],
        [ 4, 5, 6 ],
        [ 7, 8, 9 ]
    ]
}

Polygon

Closed polygon formed by linear sequence of points. The first and last points are the same.

Name Type Mandatory Description
type string Y Constant Polygon
points Array of Coordinate Y Points

Example

{
    "type": "Polygon",
    "points": [
        [ 1, 2, 1 ],
        [ 3, 4, 2 ],
        [ 5, 6, 3 ],
        [ 7, 8, 4 ],
        [ 1, 2, 1 ]
    ]
}

Arc

Circular arc defined by start point, point on the arc and end point.

Note

Arc is not used as a standalone top-level geometry. It is a part of CompositePolyline, CompositePolygon or Boundary geometries.

Name Type Mandatory Description
type string Y Constant Arc
points Array of Coordinate Y Points. Exactly 3 points must be specified.

Example

{
    "type": "Arc",
    "points": [
        [ 0, 1, 0 ],
        [ 0.5, 0.5, 0 ],
        [ 0, 0, 0 ]
    ]
}

PolylineSegment

Polyline | Arc

CompositePolyline

Collection of linear segments formed by polyline and arc segments. Starting and ending points of internal segments are the same (end point of segment 1 is the same as start point of segment 2, etc).

Name Type Mandatory Description
type string Y Constant CompositePolyline
geometries Array of PolylineSegment Y Polyline segments. Only Polyline and Arc geometries are allowed.

Example

{
    "type": "CompositePolyline",
    "geometries": [{
            "type": "Polyline",
            "points": [[0, 0, 0], [1, 1, 0]]
        }, {
            "type": "Polyline",
            "points": [[1, 1, 0], [2, 2, 0], [0, 0, 0]]
        }
    ]
}

CompositePolygon

Polygon formed by a collection of linear and circular arc segments. Starting and ending points of internal segments are the same (end point of segment 1 is the same as start point of segment 2, etc).

Name Type Mandatory Description
type string Y Constant CompositePolygon
geometries Array of PolylineSegment Y Polygon segments. Only Polyline and Arc geometries are allowed.

Example

{
    "type": "CompositePolygon",
    "geometries": [
        {
            "type": "Polyline",
            "points": [
                [ 0, 0, 0 ],
                [ 1, 0, 0 ],
                [ 1, 1, 0 ]
            ]
        },
        {
            "type": "Polyline",
            "points": [
                [ 1, 1, 0 ],
                [ 1, 2, 0 ],
                [ 0, 1, 0 ]
            ]
        },
        {
            "type": "Arc",
            "points": [
                [ 0, 1, 0 ],
                [ 0.5, 0.5, 0 ],
                [ 0, 0, 0 ]
            ]
        }
    ]
}

Boundary

Polygon with zero or more holes.

Name Type Mandatory Description
type string Y Constant Boundary
exterior Geometry Y Exterior Polygon or CompositePolygon geometry.
holes Array of Geometry Geometry collection of holes. Each hole must be a Polygon or CompositePolygon.

Example

{
    "type": "Boundary",
    "exterior": {
        "type": "Polygon",
        "points": [
            [ 0, 0, 0 ],
            [ 5, 5, 0 ],
            [ 3, 3, 0 ],
            [ 4, 4, 0 ],
            [ 0, 0, 0 ]
        ]
    },
    "holes": {
        "type": "GeometryCollection",
        "geometries": [
            {
                "type": "Polygon",
                "points": [
                    [ 0, 0, 0 ],
                    [ 1, 1, 0 ]
                ]
            },
            {
                "type": "CompositePolygon",
                "geometries": [
                    {
                        "type": "Polygon",
                        "points": [
                            [ 0, 0, 0 ],
                            [ 1, 1, 0 ]
                        ]
                    },
                    {
                        "type": "Arc",
                        "points": [
                            [ 0, 0, 0 ],
                            [ 1, 2, 0 ],
                            [ 1, 1, 0 ]
                        ]
                    }
                ]
            }
        ]
    }
}

GeometryCollection

Heterogenous collection of multiple geometries. This type is not used for top-level geometries in NetWorks.

Name Type Mandatory Description
type string Y Constant GeometryCollection
geometries Array of Geometry Child geometries.

Example

{
    "type": "GeometryCollection",
    "geometries": [{
            "type": "OrientedPoint",
            "origin": [1, 2, 3],
            "orientation": [1, 1, 0]
        }, {
            "type": "Polyline",
            "points": [
                [1, 2, 3],
                [4, 5, 6],
                [7, 8, 9]
            ]
        }, {
            "type": "Polygon",
            "points": [
                [1, 2, 1],
                [3, 4, 2],
                [5, 6, 3],
                [7, 8, 4],
                [1, 2, 1]
            ]
        }
    ]
}

Raster

NetWorks Core Raster geometry.

Name Type Mandatory Description
type string Y Constant Raster
points Array of Coordinate Y Raster polygon. 5 points are expected.
filename string Name of the file with raster geometry.
matrix Array of Number Raster transformation 4x4 matrix stored in as rows (each inner array is a row in the matrix). The rightmost column of the array is omitted.

Example

{
    "type": "Raster",
    "polygon": {
        "type": "Polygon",
        "points": [
            [1, 2, 1],
            [3, 4, 2],
            [5, 6, 3],
            [7, 8, 4],
            [1, 2, 1]
        ]
    },
    "filename": "test.jpg",
    "matrix": [[0, 0, 0], [1, 1, 1], [2, 2, 2], [3, 3, 3]]
}
