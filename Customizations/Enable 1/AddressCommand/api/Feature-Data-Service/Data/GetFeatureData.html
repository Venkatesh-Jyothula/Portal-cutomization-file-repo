GetFeatureData

Returns feature data.

Request

Method

GET

URL Template

/feature/{fno}/{fid}[?cno={cno}][&gf={gf}][&dims={dims}] [&resolution={resolution}]

Path variables

Name Type Mandatory Description
{fno} int Y G3E_FNO
{fid} int Y G3E_FID

Query params

Name Type Mandatory Description
{cno} string Comma-separated list of G3E_CNOs to retrieve. When not specified, all components are retrieved.
{gf} string Output geometry format. Allowed values: wkt, networksjson, geojson. Default is wkt.
{dims} integer Dimensions of the geometries in output. Allowed values: 2, 3. Default is 3.
{resolution} double Resolution (ground units per pixel). When provided, the arc geometries are stroked to match this resolution. When not provided, the geometries are returned as stored in the database.

Response

Serialized feature data.

Example

Example Request

http://machinename/fds/feature/323/1002458?gf=wkt&dims=3
