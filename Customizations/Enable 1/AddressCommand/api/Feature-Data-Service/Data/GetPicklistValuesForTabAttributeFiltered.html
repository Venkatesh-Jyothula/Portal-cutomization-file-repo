GetPicklistValuesForTabAttributeFiltered

Returns content of picklist table for given G3E_TANO. Values of other attributes required for field value filters are passed in the request body and are used to filter the picklist values.

Request

Method

POST

URL Template

/picklist/tabattribute/{tano}[?key={key}&skip={skip}&count={count}]

Path variables

Name Type Mandatory Description
{tano} int Y G3E_TANO

Query params

Name Type Mandatory Description
{key} string Key value of the picklist (value of the G3E_TANO). When present, it is used to filter the picklist data.
{skip} int 0-based offset of the first row to retrieve. Must be 0 or more.
{count} int Number of records to retrieve. Must be 1 or more.

Body

Body contains a single property named attributes, which is a JSON object. Each property of this object is a G3E_ANO value, the value of the property is the attribute value. Values use attribute value encoding as in ProcessTransactions request.

Response

The same response as GetPicklistValuesForTabAttribute.

Example

Example Request

http://machinename/fds/picklist/tabattribute/2300?skip=0&count=10

Body

{
  "attributes": {
    "22010102": "2",
    "22010181": "3"
  }
}

Example Response

See example in GetPicklistValuesForTabAttribute.
