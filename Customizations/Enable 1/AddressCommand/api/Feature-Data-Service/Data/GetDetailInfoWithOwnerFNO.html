GetDetailInfoWithOwnerFNO

Get parameters of a detail window by its detail identifier and the G3E_FNO of the owner.

Request

Method

GET

URL Template

/details/detail/{detailid}/{fno}[?type={type}]

Path variables

Name Type Mandatory Description
{detailid} int Y Detail identifier.
{fno} int Y G3E_FNO of the owner.

Query params

Name Type Mandatory Description
{type} string 0 = Detail, 1 = Schematic. When omitted, both types are returned.

Response

Data of the detail window, with storage, projected and geographic (WGS84) MBR.

Example

Example Request

http://machinename/fds/details/detail/55/323
