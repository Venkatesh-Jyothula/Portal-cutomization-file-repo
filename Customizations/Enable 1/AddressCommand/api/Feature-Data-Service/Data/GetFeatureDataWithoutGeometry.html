GetFeatureDataWithoutGeometry

Returns feature data without geometry attributes.

Request

Method

GET

URL Template

/feature/{fno}/{fid}/attributes[?cno={cno}]

Path variables

Name Type Mandatory Description
{fno} int Y G3E_FNO
{fid} int Y G3E_FID

Query params

Name Type Mandatory Description
{cno} string Comma-separated list of G3E_CNOs to retrieve. When not specified, all components are retrieved.

Response

Serialized feature data.

Example

Example Request

http://machinename/fds/feature/323/1002458?cno=5633,5648
