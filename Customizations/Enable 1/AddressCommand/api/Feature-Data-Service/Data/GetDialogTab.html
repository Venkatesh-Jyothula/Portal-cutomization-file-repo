GetDialogTab

Return dialog tab content (tab attributes with their values translated by picklists) from the database.

Request

Method

GET

URL Template

/dialog/tab/{dtno}/{fno}/{fid}[&attributes={attributes}]

Path variables

Name Type Mandatory Description
{dtno} int Y G3E_DTNO
{fno} int Y G3E_FNO
{fid} int Y G3E_FID

Query params

Name Type Mandatory Description
{attributes} Int Flag: 1=include dialog tab attribute metadata in response. Other values: attributes are not included. Default is 1.

Response

Dialog tab data, optionally with dialog tab attribute metadata. For dialog tabs with repeating components, each row has property cid with G3E_CID of the repeating component instance.

Each row contains a map with G3E_TANO as key. Values are returned as objects with properties: c (string), n (number), d (date-time). Attributes with picklists have additional property t with display value for the picklist key.

Example Request

http://machinename/fds/tabs/323/1002458?type=Edit
