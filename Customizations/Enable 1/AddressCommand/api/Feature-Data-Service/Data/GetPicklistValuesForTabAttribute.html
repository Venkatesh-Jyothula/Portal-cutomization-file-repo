GetPicklistValuesForTabAttribute

Returns content of picklist table G3E_TANO. This API implements the same logic as Dialog Web Service GetPicklistTano method.

Request

Method

GET

URL Template

/picklist/tabattribute/{tano}[?skip={skip}&count={count}]

Path variables

Name Type Mandatory Description
{tano} int Y G3E_TANO

Query params

Name Type Mandatory Description
{skip} int 0-based offset of the first row to retrieve. Must be 0 or more.
{count} int Number of records to retrieve. Must be 1 or more.

Response

The fields property contains an array of field names returned in each item of the items property. First field name is always the key, second always the display value, as defined in picklist metadata. Additional column names are optional.

Example

Example Request

http://machinename/fds/picklist/tabattribute/2300?skip=0&count=10
