GetDialogTabFromData

Return dialog tab content from feature component data sent by the client in the request. The method differs from the GetDialogTabData in that it accepts the current and related component data in request, whereas GetDialogTabData retrieves the feature component data from the database. The purpose if this method is to allow the clients to construct dialog tab content interactively from current state of a feature being edited on the client.

Request

Method

POST

URL Template

/dialog/tab/{dtno}

Body

Body contains the row data of the component instance(s) displayed on the dialog tab and necessary related components (non-repeating components of the current feature). The format is the same as the response from the GetFeatureData method.

Response

See response from GetDialogTabData.
