ConvertGeometryFormat

Convert geometries into a selected format. The output can be 2D or 3D. Optionally, complex geometries with circular arcs can be stroked and simplified.

Request

Method

POST

URL Template

/geometry/convert?gf={gf}[&dims={dims}][&resolution={resolution}]

Query params

Name Type Mandatory Description
gf string Y Output geometry format. Allowed values: wkt, networksjson, geojson. Default is wkt.
dims integer Dimensions of the output. Allowed values: 2, 3. Default is 3.
resolution double Resolution (ground units pre display unit). When specified, all circular arcs are stroked to polylines and geometries are simplified (consecutive polyline segments are merged).

Body

A JSON object with one or more properties. Each property contains a single geometry. The property name is repeated in the response to allow matching geometries in request and response. There is no restriction on the property names (beyond standard JSON rules). Geometries in the request can be specified in mixed formats. The API will deserialize the geometry according to its format specifier.

Response

Data of the detail window, with storage, projected and geographic (WGS84) MBR.

Example

Example Request

http://machinename/fds/geometry/convert?gf=geojson&dims=2

Body

{
    "a": {
        "networksjson": {
            "type": "OrientedPoint",
            "origin": [
                1,
                2,
                0
            ],
            "orientation": [
                0.4472142375143948,
                0.8944268699924094,
                0
            ]
        }
    },
    "b": {
        "wkt": "LINESTRING Z(1 2 3,4 5 6,7 8 9)"
    }
}

Example Response

{
    "a": {
        "geojson": {
            "type": "Point",
            "coordinates": [
                1,
                2
            ],
            "orientation": [
                0.4472142375143948,
                0.8944268699924094
            ]
        }
    },
    "b": {
        "geojson": {
            "type": "LineString",
            "coordinates": [
                [
                    1,
                    2
                ],
                [
                    4,
                    5
                ],
                [
                    7,
                    8
                ]
            ]
        }
    }
}
