Analytical Service

Search

Method Uri Description
GET /Details Gets the list of all details.
GET /Details/fnos Get the list of feature numbers that have details associated with them.
GET /Details/Fnos/{fno} Gets the details associated with the given feature number.
GET Details/Fnos/{fnos}/Names?name={name} Get details by fno and name.
GET /Details/Names?name={name} Get details by name.
GET /Quicksearches Get quicksearch definitions.
GET /Execute/{amno} Execute a search.
GET /Results/Delete Delete search results from the database.
GET /search/searches Get search definitions.
GET /search/searches/categories Get the list of search categories.
GET /search/searches/{acno} Get search definitions by ACNO.
GET /Search/Detail/{detailId} Gets the MBR of a detail given its detail number.
GET /Search/Detail/{detailId}/{fno} Gets the MBR of a detail given its detail number and feature number.
GET /Schematics Gets the list of all schematics.
GET /Schematics/Fnos Get the list of FNOs that have schematics.
GET /Schematics/Fnos/{Fno} Get schematics by FNO.
GET /Schematics/Fnos/{Fno}/Names?name={name} Get schematics by FNO and name.
GET /Schematics/Names?name={name} Get schematics by name.
GET /Settings Get the configured search settings.
GET /picklistvalues/{amno}/{ano} Returns the picklist values for the given search parameter.
GET /PickListValues/{ano} Returns the picklist values for the given attribute number.
POST /PickListValues/{ano} Returns the picklist values for the given attribute number based on the input filters.
GET /search/results/fetch Returns all the analysis (query or trace) results corresponding to the given result identifier.

Trace

Method Uri Description
GET /Delete/{Name} Deletes the trace if exists.
POST /Execute Executes the trace and returns a tracenumber for the given input parameters.
GET /Exists/{TraceName} Returns the picklist values for the given attribute number.
GET /Hint Returns the list of hint feature instances for the given seedFid and mappingID.
GET /Parameters/{TraceMappingID} Returns the trace parameters for the given trace mapping identifier.
GET /PickListValues/{ANO} Returns true if the given tracename exists.
GET /Types Returns all trace definitions which are present in the connected database.
GET /Types/{FeatureNumber} Returns the list of trace definitions for the given feature number which are present in the connected database.
GET /SeedFNOs Returns all the FNO's that are eligible to perform trace.
GET /MappingId Returns the MappingId for the given TraceId, SeedFno, and either TraceType or TraceUsername.
GET /Reports/{mappingId} Returns the list of valid report for given mappingID.
POST /ComputeMarkers/{tno} Computes marker points for executed cost constraint trace.
POST /computemarkerpoints Computes the marker location points for an executed trace based on user defined stop criteria.

Results

Method Uri Description
GET /Traces Returns all the executed traces, each containing TRACEID and TRACENAME.
GET /Trace/{Tno} Returns all the trace results corresponding to the given trace number (tno).

Style

Method Uri Description
GET /PointStyles Returns the named point styles.
GET /LinePatterns Returns the named line patterns.

Area of Interest

Method Uri Description
GET /Areas Get a list of all areas of interest. The list can be filtered based on an optional name parameter.

Coordinate System

Method Uri Description
GET /Names Returns all coordinate system names present in the connected configuration.
GET /Parameters Returns a list of coordinate systems defined within a connected configuration along with their parameters.
GET /Transform Transforms an array of 2d points from source to destination coordinate system.
GET /Transform3d Transforms an array of 3d points from source to destination coordinate system. This method is useful if elevation data is involved.
