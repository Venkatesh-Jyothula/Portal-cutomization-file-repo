Get feature instance geometries

Get geometries of a feature instance. Depending on the filter conditions, the method returns primary geographic or detail components, all geographic or detail components, optionally also synthesized components. When legend settings number are specified, the components are filtered by G3E_ALTERNATEGEOORDINAL of the legend.

Request

Method

GET

URL Template

/geometry/{G3E_FNO}/{G3E_FID}?g={geographic}&d={detail}&a={all}&s={synthesized}&lsno={lsno}&tt={tooltips}&detailid={detailid}

Parameters

Name Type Mandatory Description
G3E_FNO Integer Y G3E_FNO
G3E_FID Integer Y G3E_FID
g Integer When 1, returns geographic components. Default is 0.
d Integer When 1, returns detail components. Default is 0.
a Integer When 0, returns only primary geometries. When 1, return all geometries. Default is 0.
s Integer When 1, returns synthesized components. Default is 0.
lsno Integer When set, only components with G3E_ALTERNATEGEOORDINAL of this legend are returned.
tt Integer When 1, returns component view tooltip in property TT.
detailid Integer Detail identifier (G3E_DETAILID). When present, detail component views are filtered to this value.

Allowed combinations of parameter values:

geographic detail all GTComponentGeometryConstants equivalent Note
1 gtddcgPrimaryGeographic Primary Geographic Components
1 1 gtddcgAllGeographic All Geographic Components
1 1 gtddcgAllDetail All Detail Components
1 gtddcgPrimaryDetail Primary Detail Components
1 1 gtddcgAllPrimary All Primary Components
1 1 1 All Geographic and Detail Components

Response

If a feature is available, the HTTP status code is 200 and response body contains data of the feature as GeoJSON FeatureCollection. If there are multiple component instances, each instance is returned as separate GeoJSON Feature.

If a feature is not available for input parameters, HTTP status code is 200 and the FeatureCollection contains no features.

If input parameters are invalid (non existent FNO, no primary geometry defined), HTTP status code is 400 and the response body contains error description.

Style and label rules are not evaluated. The response does not contain properties which allow styled rendering of the geometry (SNO, ROT, LBL, ALN). The ID property is formatted as {G3E_FID},{G3E_FNO},{G3E_CID},{G3E_CNO},{G3E_VIEW}.

Sample Request

http://machinename/NetworksVectorService/geometry/323/1027199?g=1&a=1&s=0
