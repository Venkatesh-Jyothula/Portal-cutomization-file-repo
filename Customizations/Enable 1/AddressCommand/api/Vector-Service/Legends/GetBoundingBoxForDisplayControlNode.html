GetBoundingBoxForDisplayControlNode

Get bounding box for a legend. Coordinates are returned in configuration projection.

Request

Method

GET

URL Template

/displaycontrol/{G3E_LSNO}/{G3E_DCROWNO}/bbox

Request Parameters

Parameter Name Description
G3E_LSNO Legend settings number
G3E_DCROWNO Display control node number

Response

Bounding box.

Sample

Sample Request

http://machinename/NetworksVectorService/displaycontrol/7/3060000/bbox

Sample Response

{
    "minx": 4498324.28484586,
    "miny": 5912526.72812445,
    "maxx": 4507332.86025346,
    "maxy": 5932636.38186112
}

Sample Response (no data found)

{
    "minx": null,
    "miny": null,
    "maxx": null,
    "maxy": null
}
