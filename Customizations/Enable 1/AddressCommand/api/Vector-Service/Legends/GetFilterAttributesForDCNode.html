GetFilterAttributesForDCNode

Get list of attributes for ad-hoc filtering of display control node and its children.

Request

Method

GET

URL Template

/displaycontrol/{G3E_LSNO}/{G3E_DCROWNO}/filterattributes

Request Parameters

Parameter Name Description
G3E_LSNO NetWorks legend settings number
G3E_DCROWNO Display control node number

Response

Instance of FilterAttributesResponse.

Type FilterAttributesResponse

Property Type Description
attributes FilterAttribute[] List of filter attributes.

Type FilterAttribute

Property Type Description
G3E_ANO int G3E_ANO.
G3E_FIELD string Name of the attribute in the published component view.
G3E_PNO int? Picklist number (G3E_PNO). Optional.
dataType string Data type of attribute. Allowed values: string, integer, float, dateTime.
