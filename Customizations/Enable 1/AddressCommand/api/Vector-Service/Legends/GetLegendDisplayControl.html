GetLegendDisplayControl

Get display control tree for the legend settings identified by G3E_LSNO.

Request

Method

GET

URL Template

/displaycontrol/{G3E_LSNO}/dc

Request Parameters

Parameter Name Description
G3E_LSNO NetWorks legend settings number

Response

Hierarchical structure with display control nodes. Child entries are under children property.

Sample

Sample Request

http://machinename/NetworksVectorService/displaycontrol/7/dc
