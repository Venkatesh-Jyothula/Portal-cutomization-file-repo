GetLegendEntries

Get list of legend entries for the legend settings identified by G3E_LSNO

Request

Method

GET

URL Template

/displaycontrol/{G3E_LSNO}/entries

Request Parameters

Parameter Name Description
G3E_LSNO NetWorks legend settings number

Response

Array of legend entry descriptors.

Sample

Sample Request

http://machinename/NetworksVectorService/displaycontrol/7/entries

Sample Response

[{
    "leno": "1240001",
    "name": "Top-Topographic-Raster-Arial View",
    "locatable": 1,
    "displayMode": 1
 }, {
    "leno": "1240000",
    "name": "Top-Topographic-Raster",
    "locatable": 1,
    "displayMode": 1
 }, 
    ...
]
