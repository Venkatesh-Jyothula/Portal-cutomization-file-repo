GetTooltips

Get formatted tooltip for feature classes, feature instances or component instances in one call..

Request

Method

POST

URL Template

/tooltip

Rules

Request is an object with an array of feature class, feature instance or component instance identifiers in Features property. Rules:

  • If only G3E_FNO is specified, the service returns feature class name.
  • If only G3E_FNO and G3E_FID are specified, the service returns feature instance tooltip.
  • If only G3E_FNO, G3E_FID, G3E_CNO are specified, the service returns component instance tooltip (G3E_CID=1).
  • If G3E_FNO, G3E_FID, G3E_CNO and G3E_CID are specified, the service returns component instance tooltip for this key.
  • If the service does not found any tooltip for the given key, it returns null.

Response

The response is an array of objects with t property. The order of objects corresponds to the order of identifiers in request.
