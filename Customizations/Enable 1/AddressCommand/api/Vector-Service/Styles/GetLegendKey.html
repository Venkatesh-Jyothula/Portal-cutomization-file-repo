GetLegendKey

Returns legend key i.e. style rules (name and style identifier) used to render the provided list of legend entries.

Request

Method

POST

URL Template

/style/key

Request Parameters

None.

Response

Response is a dictionary keyed by G3E_LENO with legend entry information (leno, name) and a list of styles in the styles property. Each style object has two properties: sno with style identifier and name with user name of the style rule.

Sample

Sample Request

http://machinename/NetworksVectorService/style/key

{
    "lsno": 7,
    "entries": [{
            "l": 3060000
        }, {
            "l": 3060700
        }, {
            "l": 3060300
        }, {
            "l": 3060500
        }, {
            "l": 3060200
        }, {
            "l": 306000
        }, {
            "l": 306400
        }
    ]
}
