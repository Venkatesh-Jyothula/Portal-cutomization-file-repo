GetStyleMap

Get style definitions.

Request

Method

GET

URL Template

/style/map

Request Parameters

None.

Response

Response is a structure with 2 dictionaries.

  • styles - Contains list of style definitions indexed from 0. The ID is temporary only.
  • map - Maps G3E_SNO to style definition in styles.

Sample

Sample Request

http://machinename/NetworksVectorService/displaycontrol/7/info
