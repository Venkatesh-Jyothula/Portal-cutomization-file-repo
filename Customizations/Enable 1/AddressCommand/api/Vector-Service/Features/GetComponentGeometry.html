GetComponentGeometry

Get geometry of geographic component of a feature.

Request

Method

GET

URL Template

/data/{G3E_FNO}/{G3E_FID}/{G3E_CNO}

Parameters

Name Type Mandatory Description
G3E_FNO Integer Y G3E_FNO
G3E_FID Integer Y G3E_FID
G3E_CNO Integer Y G3E_CNO

Response

If a feature is available, the HTTP status code is 200 and response body contains data of the feature as GeoJSON FeatureCollection. If there are multiple component instances, each instance is returned as separate Feature.

If a feature is not available for input parameters, HTTP status code is 200 and the FeatureCollection contains no features.

If input parameters are invalid (non existent FNO, no primary geometry defined), HTTP status code is 400 and the response body contains error description.
