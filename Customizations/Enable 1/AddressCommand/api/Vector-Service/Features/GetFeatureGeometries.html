GetFeatureGeometries

Get geometry of geographic component instance of multiple features in one call.

Request

Method

POST

URL Template

/data/geometry

Rules

Request is an object with an array of feature class, feature instance or component instance identifiers in Features property. Rules:

  • If only G3E_FNO and G3E_FID are specified, the service returns feature primary geometry of the feature.
  • If only G3E_FNO, G3E_FID, G3E_CNO are specified, the service returns component instance geometry (G3E_CID=1).
  • If G3E_FNO, G3E_FID, G3E_CNO and G3E_CID are specified, the service returns component instance geometry for this key.

Response

If a feature is available, the HTTP status code is 200 and response body contains data of the feature as GeoJSON FeatureCollection. If there are multiple component instances and G3E_CID is not specified, each instance is returned as separate Feature. Property TT of the GeoJSON feature contains formatted tooltip of the component view.

If a feature is not available for input parameters, it is not included in the response FeatureCollection. HTTP status code is 200.

If input parameters are invalid (non existent FNO, no primary geometry defined), HTTP status code is 400 and the response body contains error description.
