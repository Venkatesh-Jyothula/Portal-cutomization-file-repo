GetFeature

Get a single feature specified by its identifiers.

Request

Method

GET

URL Template

/data/{G3E_LSNO}/{G3E_LENO}/{G3E_FNO}/{G3E_FID}/{G3E_CNO}/{G3E_CID}

Parameters

Name Type Mandatory Description
G3E_LSNO Integer Y G3E_LSNO
G3E_LENO Integer Y G3E_LENO
G3E_FNO Integer Y G3E_FNO
G3E_FID Integer Y G3E_FID
G3E_CNO Integer Y G3E_CNO
G3E_CID Integer Y G3E_CID

Response

If a feature is available, the HTTP status code is 200 and response body contains data of the feature as GeoJSON Feature.

If a feature is not available for input parameters, HTTP status code is 204 and the response body is empty.

Sample Request

http://machinename/NetworksVectorService/data/1/2/3/4/5/6
