GetFeatures

Get feature data for selected legend settings with geometries in GeoJSON format.

Request

Method

POST

URL Template

/data[?tt={tt}]

Query parameters

Name Type Mandatory Description
tt int When set to 1, component view tooltips are returned with each geometry in property TT.

Body

Name Type Mandatory Description
lsno Integer Y G3E_LSNO
bbox Double[] Y Bounding box in CS coordinates, formatted as [XMIN, YMIN, XMAX, YMAX].
resolution Double Y* Client resolution, CS ground unit per pixel (e.g. meters per pixel). Mandatory if scale not specified.
scale Double Y* Display scale. Use 500 for 1:500, etc. Mandatory only if resolution is not specified. If scale is specified, it has priority over resolution.
detailId Integer N G3E_DETAILID. If specified, the results are filtered for given detail. Applicable only to detail legends.
entries LegendEntry[] Y List of legend entries to retrieve. Order of entries in the list is not important.
filters Object N Property map with filtering conditions. The conditions are referenced by f property of LegendEntry type.
features Integer[] N List of feature identifiers to use as a filter when outputting data. The array should be formatted as G3E_FNO1,G3E_FID1,G3E_FNO2,G3E_FNO2,...

Type LegendEntry

Name Type Mandatory Description
l Integer Y G3E_LENO. When "features" are specified, a special value of -3 can be used to automatically include all legend entries related to FNOs in the "features" list.
s Integer N When 1, return legend entry without scale dependency.
f String N Ad-hoc filter defined for the legend entry. The value is a reference to a property on the filters object in main request.

Response

Returns a GeoJSON FeatureCollection.

Each feature has the following properties:

Name Type Mandatory Description
ID String Y ID of the component view instance, formatted as {G3E_FID},{G3E_FNO},{G3E_CID},{G3E_CNO},{G3E_LENO}
SNO String Y G3E_SNO
LBL String N Label (for TextGeometry)
ALN Number N G3E_ALIGNMENT (for TextGeometry)
ROT Number N Rotation in radians (for TextGeometry and OrientedPointGeometry)

Using feature list

This request returns looks for features specified in features parameter in the bbox and returns all legend entries in legend settings = 7 related to these FNOs.

Sample Request

http://machinename/NetworksVectorService/data

{
    "lsno": 7,
    "bbox": [1338540.407641353, 7068952.277151424, 1338960.51271478, 7069218.015257571],
    "resolution": 0.29858214173896974,
    "entries": [{
            "l": -3
    }],
    "features": [306,1028719,306,1030520,306,1030598]
}
