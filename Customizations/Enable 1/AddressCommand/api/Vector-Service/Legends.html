Legends

Methods returning metadata on legends.

Method Uri Description
GET /displaycontrol/legends Get list of available legends.
GET /displaycontrol/{G3E_LSNO}/info Get information on legend settings with G3E_LSNO.
GET /displaycontrol/{G3E_LSNO}/entries Get legend entries for given G3E_LSNO.
GET /displaycontrol/{G3E_LSNO}/dc Get display control tree for given G3E_LSNO.
GET /displaycontrol/{G3E_LSNO}/{G3E_DCROWNO}/predefinedfilters Get list of predefined filters for display control node.
GET /displaycontrol/{G3E_LSNO}/{G3E_DCROWNO}/filterattributes Get list of filter attributes for display control node.
GET /displaycontrol/bbox Get bounding box for all data.
GET /displaycontrol/{G3E_LSNO}/bbox Get bounding box for a legend.
GET /displaycontrol/{G3E_LSNO}/{G3E_DCROWNO}/bbox Get bounding box for a display control node.
GET /displaycontrol/{G3E_LSNO}/entry/{G3E_LENO}/bbox Get bounding box for a legend entry.
