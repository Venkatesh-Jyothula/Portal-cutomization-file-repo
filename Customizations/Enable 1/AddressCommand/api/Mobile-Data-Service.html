Mobile Data Service

The HxGN NetWorks Mobile Data Service provides RESTful APIs for bulk publishing of vector tiles and HxGN NetWorks Core metadata and data.

Publish Data and Tiles

Method Uri Description
GET /area/names Gets the list of all AOI's configured in the database.
GET /area/{names} Gets the information for the given area of interests (AOIs).
GET /region/names Gets the list of all regions configured as regional subsets that are mapped to configurations within the database.
GET /region/{names} Gets the information for the given regions.
POST /publish/start Initiates a task to bulk publish vector tiles and HxGN NetWorks Core data and metadata for given filter polygons.
GET /publish/status/{taskid} Returns the current status of the given publish task.
GET /fetch/data Downloads the published data file(s) for the completed publish task.
GET /config Returns the URL of the HxGN NetWorks Vector Tile Service associated with the current HxGN NetWorks Mobile Data Service.
