Get Picklist Values

Returns the picklist values for the given attribute number.

GET

Request URL Template

http://{HostName}/{JobServiceName}/pickListvalues/{ano}

Request Parameters

Parameter Name Description Optional
Ano Desired attribute number as string. No
pageNo Page Number. Yes
pageSize Page Size. Yes
Filter Return only values that match this filter. Yes

Sample Request

http://hostname/NetworksJobService/picklistvalues/340014?filter=Proposed&pageNo=1&pageSize=5

Sample Response

{
    "items": [
        {
            "Key": "Proposed",
            "Value": "Proposed"
        },
        {
            "Key": "Proposed Dist",
            "Value": "Proposed Dist"
        },
        {
            "Key": "Proposed Removed",
            "Value": "Proposed Removed"
        },
        {
            "Key": "Proposed Removed Dist",
            "Value": "Proposed Removed Dist"
        },
        {
            "Key": "Proposed Retired",
            "Value": "Proposed Retired"
        }
    ],
    "totalCount": 7
}

Remarks

This method supports both pagination and typeahead filtering.

Returns the list of picklist values, in pages honoring the page size, when it is called with pagination parameters.

Returns the list of picklist values starting with the filter parameter value, when it is called with filter parameter.

Here, the picklist values are ordered based on the field 'G3E_ORDERBYKEY'.

Response contains:

'key' is the picklist keyname

'value' is the picklist keyvalue
