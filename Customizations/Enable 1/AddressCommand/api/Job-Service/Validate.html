Validate

Validate the specified job's pending edits.

POST

Request URL Template

http://{HostName}/{JobServiceName}/job/{jobId}/validate?pageNo={pageNo}&pageSize={pageSize}

Request Parameters

A list of validation errors is returned for the specified job. Job has to have pending edits. PageNo and pageSize are used for paging the result.

Parameter Name Description
jobId Job identifier
pageNo Number of the page for paged result.
pageSize Size of one page for paged result.

Sample Request

http://localhost/NetworksJobService/job/j8045/validate

Sample Response

The list of validation errors for job 'j8045'.

[
    {
        "ErrorDescription": "desc",
        "ErrorLocation": "loc",
        "ErrorPriority": "P4",
        "FeatureKey": {
            "Fno": 100,
            "Cno": 31,
            "Fid": 1053890,
            "Cid": 1
        }
    }
]

GET

Validate all pending edits within the specified job. The edited features will be checked to make sure that all required components, attributes and relationships have been created. Also, the Validate method of all associated Functional interfaces and Validation interfaces will be executed.

Request URL Template

http://{HostName}/{JobServiceName}/validate/{jobId}

Request Parameters

Parameter Name Description
jobId The job identifier for the job. It must be an exact match to the job identifier in the job table.

Sample Request

http://localhost/NetworksJobService/validate/WmsTestJob

Sample Response

A JSON array of validation error objects is returned. Each object specifies the feature keys, error priority, error description and error location. The error priority values are P1, P2, P3 and P4 where P1 is the most severe. Only the validation errors whose error priority is higher than the ValidationPriorityFilter value from the G3E_GENERALPARAMETER table will be included in the response.

// JSON array of validation errors.
[
  { 
    "Fno":<featureNumber>,
    "Fid":<featureId>,
    "Cno":<componentNumber>,
    "Cid":<componentId>,
    "ErrorPriority":<either "P1","P2","P3", or "P4">,
    "ErrorDescription":<error message>,
    "ErrorLocation":<software component that reported error>
  },
  ...
]

Remarks All pending edits within the specified job are validated. A job cannot be posted if there are any validation errors that are higher than or equal to the ValidationPriorityThreshold value from the G3E_GENERALPARAMETER table.
