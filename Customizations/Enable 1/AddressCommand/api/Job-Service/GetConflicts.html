GetConflicts

Gets the list of conflicts between job edits and master deltas for the specified job.

GET

Request URL Template

http://{HostName}/{JobServiceName}/conflicts/{jobIdList}?pageNo={pageNo}&pageSize={pageSize}

Request Parameters

A list of information about conflicts between job edits and master deltas is returned for each of the specified jobs. PageNo and pageSize are used for paging the result.

Parameter Name Description
jobIdList A comma separated list of job identifiers. The job identifiers must be an exact match to the job id in the job table.
pageNo Number of the page for paged result.
pageSize Size of one page for paged result.

Sample Request

http://localhost/NetworksJobService/conflicts/job123
