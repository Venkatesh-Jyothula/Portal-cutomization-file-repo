GetPendingEdits

Gets the list of pending edits for the specified jobs.

GET

Request URL Template

http://{HostName}/{JobServiceName}/pendingedits/{jobIdList}?v={version}&pageNo={pageNo}&pageSize={pageSize}

Request Parameters

A list of information about pending edits (feature name, feature keys and job name) is returned for each of the specified jobs. Parameter 'v' (version) is used to distinguish old (legacy) and current response format. If omitted, v defaults to 0 and therefore legacy format is used. Using version parameter without value causes use of current response format. PageNo and pageSize are used for paging the result.

Parameter Name Description
jobIdList A comma separated list of job identifiers. The job identifiers must be an exact match to the job id in the job table.
v Version of response format. 0 - legacy, 1 - current. Default is 0. If used without value, then 1.
pageNo Number of the page for paged result.
pageSize Size of one page for paged result.

Sample Request

http://localhost/NetworksJobService/pendingedits/job1,job2?v

Sample Response

The list of features that have been edited in job 'job1' followed by the list of features edited in job 'job2' will be returned.

Remarks This method supports pagination. It returns the job information in pages honoring the page size, when pagination parameters are specified. The response header will contain paging attributes to help the clients keep track of what page they are on. For example, when pagination parameters are passed on the request, the response header will contain extra attributes like the following:

X-Paging-PageCount: 8

X-Paging-PageNo: 3

X-Paging-PageSize: 10

X-Paging-TotalRecordCount: 72
