CreateJob

Creates a new job with the specified job id, if specified. The job attributes for specified jobDialogType are returned. These attributes can be edited and passed into the EditJob API for updating.

Request body in POST version is optional. If present, it can contain job properties which are set at the time of creation of the job. Only non-readonly parameters for specified jobDialogType can be passed in.

POST

Request URL Template

http://{HostName}/{JobServiceName}/job/{jobId?}?jobDialogType={jobDialogType}

Request Parameters

If no jobId is provided, it is generated by the service.

Parameter Name Description
jobId Job identifier
jobDialogType Job dialog type identifier, specifying set of properties returned for job.

Sample Request

http://localhost/NetworksJobService/job/userEdits252

Sample Response

Create new job with id 'userEdits252'.

{
    "Identifier": "userEdits252",
    "Description": "",
    "Owner": "ADMIN",
    "Status": "Open",
    "Properties": []
}

Sample Request with job properties in request body

http://localhost/NetworksJobService/job/userEdits252

Request body

{
    "Description": "User XYZ field edits",
    "Properties": [
        {
            "FieldName": "G3E_JOBCLASS",
            "Value": "12"
        }
    ]
}

GET

Request URL Template

http://{HostName}/{JobServiceName}/create/{jobId?}

Request Parameters

If no jobId is provided, it is generated by the service.

Parameter Name Description
jobId Optional. The job identifier for the new job. Job identifiers cannot be reused. They must be unique. If no jobId is specified, then a default job identifier is generated.
jobDialogType Optional. Specifies the value of the G3E_TYPE field from the G3E_DIALOGS_OPTABLE that is used to define which properties are returned in the response. When no jobDialogType parameter is specified, the response will only contain the job identifier, owner, status and description.

Sample Request

http://localhost/NetworksJobService/create/16255?jobDialogType=G3E_NEWJOB
