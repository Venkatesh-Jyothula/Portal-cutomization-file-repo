Translate Feature State

Translate specified features to the default next state or the specified next state based on their current state; or return a list of possible next states based on the current state of the features.

POST

Request URL Template

http://{HostName}/{JobServiceName}/translatefeaturestate/{jobid}/{newState?}[? useDefault={true | false} ]

Request Parameters

Parameter Name Description
jobId The job identifier for the job.
newState Optional. Specifies the new state value for the feature state attribute of all input features. If the newstate parameter is omitted and the useDefault query parameter is omitted or false, then the response shows the list of possible next state values based on the current feature state value of the features.
useDefault Optional. Determines whether the default next state in the transitions metadata will be used when the newstate parameter is omitted.

Post Body Template

// JSON array of objects in POST body
[ { "Fno": fnoValue1, "Fid": fidValue1}, { "Fno": fnoValue2, "Fid": fidValue2}, ... ]

Post Body

Post Body Name Description
Feature List Array of feature objects (Fno and Fid).

Sample Request

http://localhost/NetworksJobService/translatefeaturestate/WmsTestJob?useDefault=false

Sample Post Body

[ { "Fno": 100, "Fid": 3759617},{ "Fno": 326, "Fid": 3747378},{ "Fno": 100, "Fid": 3759633} ]

Sample Response The response is a list of objects, one for each distinct current state from the set of input Fids. Each object shows the current state, its new state (if a transition was successful), its default next state (if it has one) and the set of next states that can be transitioned to. For example, if the input features are currently in either the "Proposed" or "In Service" feature state, then response would be as follows: (Note: actual progression of feature states is controlled by each customer's metadata).

[
    {
        "CurrentState": "Proposed",
        "NewState": "",
        "DefaultNextState": "Constructed",
        "NextStates": [
            "Constructed",
            "Conceptual"
        ]
    },
    {
        "CurrentState": "In Service",
        "NewState": "",
        "DefaultNextState": "Proposed Removed",
        "NextStates": [
            "Proposed Removed",
            "Out of Service",
            "Proposed Retired"
        ]
    }
]

Since the set of input features in the Post body doesn't have any common next state value to transition to, no new state value can be specified on the request. However, since all features have a metadata defined default next state value, the request can be sent again with useDefault=true to make each feature transition to its default next state. The example request and response are shown below:

Sample Request 2

http://localhost/NetworksJobService/translatefeaturestate/WmsTestJob?useDefault=true

Sample Response 2 Note that each current state transitioned to default next state from the response above and is shown as the NewState. After a successful state transition where NewState has a value, the DefaultNextState and NextStates list show the possible states from the NewState value.

[
    {
        "CurrentState": "Proposed",
        "NewState": "Constructed",
        "DefaultNextState": "In Service",
        "NextStates": [
            "In Service",
            "Out of Service"
        ]
    },
    {
        "CurrentState": "In Service",
        "NewState": "Proposed Removed",
        "DefaultNextState": "Operational Removed",
        "NextStates": [
            "Operational Removed",
            "Out of Service",
            "In Service"
        ]
    }
]

Sample Request 3

Since each of the current states from the previous request had a next state in common (i.e. "Out of Service"), that common state can be specified as the new state value for all the input features.

http://localhost/NetworksJobService/translatefeaturestate/WmsTestJob/Out%20of%20Service?useDefault=false

Sample Response 3 Note that each current state transitioned to specified next state from the request.

[
    {
        "CurrentState": "Constructed",
        "NewState": "Out of Service",
        "DefaultNextState": "In Service",
        "NextStates": [
            "In Service",
            "Proposed Retired",
            "Proposed Removed"
        ]
    },
    {
        "CurrentState": "Proposed Removed",
        "NewState": "Out of Service",
        "DefaultNextState": "In Service",
        "NextStates": [
            "In Service",
            "Proposed Retired",
            "Proposed Removed"
        ]
    }
]
