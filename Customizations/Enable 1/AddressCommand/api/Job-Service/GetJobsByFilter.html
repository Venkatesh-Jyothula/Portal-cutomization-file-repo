GetJobsByFilter

Provides job attribute information for the jobs that match one or more filter parameters.

GET

Request URL Template

http://{HostName}/{JobServiceName}/jobs?id={id}&owner={owner}&status={status}&description={description}&jobDialogType={jobDialogType}&pageNo={pageNo}&pageSize={pageSize}

Request Parameters

Any combination of the filter parameters, id, owner, status and description, can be specified. Requests must include at least one filter. The filter parameter values are used in a wild card match to the values in the corresponding columns in the job table. Multiple filters are AND'ed together in the query for jobs. JobDialogType is not a filtering condition, but it defines set of additional properties returned for each job. PageNo and pageSize are used for paging the result.

Parameter Name Description
id Job identifier
owner The user identity that created the job.
status Job status (typical values: Open, Closed, Posted, Partially Posted, Discarded).
description A brief description of what the job is about.
jobDialogType Job dialog type identifier, specifying set of properties returned for each job.
pageNo Number of the page for paged result.
pageSize Size of one page for paged result.

Sample Request

http://localhost/NetworksJobService/jobs?owner=WMSADMIN&description=Permanent

Remarks This method supports optional pagination. It returns the job information in pages honoring the page size, when pagination parameters are specified. The response header will contain paging attributes to help the clients keep track of what page they are on. For example, when pagination parameters are passed on the request, the response header will contain extra attributes like the following:

X-Paging-PageCount: 8

X-Paging-PageNo: 3

X-Paging-PageSize: 10

X-Paging-TotalRecordCount: 72
