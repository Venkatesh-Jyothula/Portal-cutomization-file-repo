GetCapabilities

Get capabilities for the WMS service for the source DDC file requested.

Workflow

If not yet in cache:

  • Find source folder under Storage.Root by provided sid.
  • Open DDC file.

Get DDC layer and BBOX information. Construct GetCapabilities document and return it.

Request

URI

GET /wms/{sid}?service=WMS&request=GetCapabilities&version=1.3.0

Parameters

Name Type Mandatory Description
sid String Y Identifier of the data source. Refers to location of the DDC file to be rendered.
service String Y Fixed: WMS
request String Y Fixed: GetCapabilities
version String Y WMS version. Allowed values: 1.3.0

Request body

N/A

Response

OGC standard GetCapabilities response.

Each layer in DDC is translated into a single WMS layer. Coordinate system equal to the NetWorks CS for the NW configuration configured for the service. Data extent is computed from DDC extents.

Normal response (200)

For XML schema, see capabilities_1_3_0.xsd

Authentication failure (401)

Returned when authorization token is missing or invalid.

Server error (500)

Returned when internal processing in the Work server fails.

For XML schema, see exceptions_1_3_0.xsd
