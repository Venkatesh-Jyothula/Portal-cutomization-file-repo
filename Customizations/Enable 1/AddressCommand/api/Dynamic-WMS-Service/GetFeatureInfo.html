GetFeatureInfo

Get info on features located on map coordinates.

Workflow

If not yet in cache:

  • Find source folder under Storage.Root by provided sid.
  • Open DDC file.

Render the map as bitmap using Locate method and find features. Return the list of feature identifiers and their attributes.

Allowed values for INFO_FORMAT are:

  • text/xml, application/vnd.ogc.gml, application/xml: Output is a wfs:FeatureCollection with geometries encoded as GML 3.2.1.

Request

URI

GET /wms/{sid}?service=WMS&request=GetFeatureInfo&version=1.3.0&BBOX={BBOX}&LAYERS={LAYERS}&CRS={CRS}&I={I}&J={J}&WIDTH={WIDTH}&HEIGHT={HEIGHT}

Parameters

Name Type Mandatory Description
sid String Y Identifier of the data source. Refers to location of the DDC file to be rendered.
service String Y Fixed: WMS
request String Y Fixed: GetMap
version String Y WMS version. Allowed values: 1.3.0
layers String Y Layers to display on map. Comma-separated list of layer names.
bbox String Y Bounding box for map extent. Value is minx,miny,maxx,maxy in units of the CRS.
crs String Y Spatial Reference System for map output. Valid values are in the capabilities document.
height Integer Y Height of map output in pixels.
width Integer Y Width of map output in pixels.
format String Y Format for the map image output. Valid values are in the capabilities document.
info_format String Y Possible values are given in the capabilities document.
styles String Styles in which layers are to be rendered. Ignored.
transparent Boolean Whether the map background should be transparent. Values are true or false. Default is true.
bgcolor String Background color for the map image. Value is in the form RRGGBB. Default is FFFFFF (white).
exceptions String Format in which to report exceptions. Default value is application/vnd.ogc.se_xml.

Request body

N/A
