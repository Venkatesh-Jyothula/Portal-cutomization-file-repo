GetMap

Get rendered bitmap for given parameters.

Workflow

When Dynamic WMS receives a request for a sid, it checks if the DDCs are already loaded in memory. If not, they are loaded from source folder under Storage.Root by provided sid. Subsequent requests hit the already loaded DDCs until they're evicted from memory cached due to inactivity.

Verify CRS matches the configuration. If BBOX is outside of extent, render empty PNG.

Render the map as bitmap. Return rendered PNG.

Notes

  • The internal operation is as stateless as possible. There's no need to call GetCapabilities (or GetLayer) before making a GetMap request.
  • A separate internal process periodically checks usage of loaded DDCs. Those which were not in uses for some time (configurable) are released from memory.

Request

URI

GET /wms/{sid}?SERVICE=WMS&REQUEST=GetMap&VERSION=1.3.0&LAYERS={LAYERS}&BBOX={BBOX}&CRS={CRS}&WIDTH={WIDTH}&HEIGHT={HEIGHT}

Parameters

Name Type Mandatory Description
sid String Y Identifier of the data source. Refers to location of the DDC file to be rendered.
service String Y Fixed: WMS
request String Y Fixed: GetMap
version String Y WMS version. Allowed values: 1.3.0
layers String Y Layers to display on map. Comma-separated list of layer names. Special value __ALL__ can be used to request all layers at once.
bbox String Y Bounding box for map extent. Value is minx,miny,maxx,maxy in units of the CRS.
crs String Y Spatial Reference System for map output. Valid values are in the capabilities document.
height Integer Y Height of map output in pixels.
width Integer Y Width of map output in pixels.
format String Y Format for the map image output. Valid values are in the capabilities document.
styles String Styles in which layers are to be rendered. The parameter is Ignored.
transparent Boolean Whether the map background should be transparent. Values are true or false. Default is true.
bgcolor String Background color for the map image when transparent is false. Value is in the form RRGGBB. Default is FFFFFF (white).
exceptions String Format in which to report exceptions. Default value is application/vnd.ogc.se_xml.

Request body

N/A

Response

PNG file with rendered map.

Authentication failure (401)

Returned when authorization token is missing or invalid.

Server error (500)

Returned when internal processing in the Work server fails.

For XML schema, see exceptions_1_3_0.xsd
