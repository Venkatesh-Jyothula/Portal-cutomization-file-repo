GetRegisteredSources

Get list of registered sources, optionally filtered.

Workflow

Retrieve list of already registered dynamic WMS sources from the storage. Filter list sources by input conditions and paging parameters.

Request

URI

GET /sources[?][kw={keywords}][&name={name}][&bbox={bbox}][&skip={skip}][&count={count}]

Parameters

Name Type Mandatory Description
keywords String Comma separated list of keywords.
name String Pattern for matching file names. Use wildcard format: ? for single character, * for multiple characters.
bbox String Bounding box to search for sources. Formatted as WMS GetMap BBOX parameter (four numbers minx,miny,maxx,maxy) in CRS configured for the Dynamic WMS instance.
skip Integer Paging parameter. Number of records to skip from start.
count Integer Paging parameter. Number of records to return.

Request body

N/A

Response

Normal response (200)

{
  "success": true,
  "sources": [
    {
      "sid": "85asd223235423454565365",
      "name": "test.dgn",
      "keywords": ["test", "test 1"]
      "bbox": {
        "minx": 123123,
        "miny": 3434343,
        "maxx": 4545454,
        "maxy": 546565,
        "crs": "EPSG:3857"
    }
  ]
}

Authentication failure (401)

Returned when authorization token is missing or invalid.

Server error (500)
