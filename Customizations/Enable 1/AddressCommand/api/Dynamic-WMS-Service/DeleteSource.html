DeleteSource

Delete a dynamically registered source.

Workflow

If already loaded, unload the source from memory.

Try to delete the source folder. Mark the source for deletion by creating a .deleted file in the source directory. This will indicate other Dynamic WMS's that the source should no longer be used. It will be removed by a background process.

Request

URI

DELETE /source/{sid}

Parameters

Name Type Mandatory Description
sid String Y Identifier of the data source. Refers to location of the DDC file to be rendered.

Request body

N/A

Success Response (200)

{
    "success": true
}

Bad Request (400) - No such sid

{
    "success": false,
    "errorCode": "ERR_INVALID_SOURCE",
    "errorMessage": "No such source"
}

Authentication failure (401)

Returned when authorization token is missing or invalid.

Server error (500)

Returned when internal processing in the Work server fails.
