FeatureRelationInfo

Gets the relationship information for the selected feature identifier and relation feature number.

GET

Request URL Template

http://{HostName}/RelationshipObject/{FNO}/{FID}?pCONF={PCONF}&pLCID={PLCID}&pJOB={PJOB}&pRFNO={PRFNO}&pLEVEL={PLEVEL}&apiVersion={apiVersion}&[ Jobs={list of job names} | ActiveJob={job name}]

Request Parameters

Parameter Name Description
PCONF Connected GTech configuration
PLCID Locale language indentifier of client
PJOB GTech job identifier. Use of pJob parameter is deprecated. If specified, it is mapped to ActiveJob={pJob value}.
PRFNO Relation Feature number
PLEVEL Recursion level
apiVersion GTDWS service version. Supported versions are 2.2.0 and 2.3.0.
ActiveJob Optional. Edits from this request are added to the job's pending edits.
Jobs Optional comma separated list of jobs whose pending edits will particate in the operation.

When there is an error from package related to metadata, a generic error will be shown. The Oracle error along with the ORA error code will be logged in database.

Sample Request

http://{HostName}/{GTDWS ServiceName}/RelationshipObject/306/7680002?apiVersion=2.2.0
