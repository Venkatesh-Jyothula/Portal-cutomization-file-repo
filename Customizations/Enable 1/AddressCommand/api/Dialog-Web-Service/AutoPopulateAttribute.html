AutoPopulateAttribute

AutoPopulates the Attributes with given TANO. The response includes both the value and key for a given G3E_TANO.FID and CID can also be given for autopopulate.

POST

Request URL Template

/AutoPopulateAttribute/{TRIGGERTANO}?pFID={PFID}&pCID={PCID}&apiVersion={apiVersion}

Request Parameters

Parameter Name Description
TRIGGERTANO Desired TriggerTANO as a string.
FID Feature Identifier.
CID Component Identifier.
apiVersion GTDWS service version. Supported versions are 2.2.0 and 2.3.0.

Case 1: FID is null

TANO and value of all attributes in the filter need to be sent in post body.

Case 2: FID and CID are not null

TANO and value of all attributes in the filter need not to be sent in post body. This is applicable when Trigger set attributes are available in multiple tabs.

Note: When CID is null/invalid first available record for the given FID will be considered.

When there is an error from package related to metadata, a generic error will be shown. The Oracle error along with the ORA error code will be logged in database.

Request Body format

[{
    "ATTRIBUTETANO": 600400346,
    "ATTRIBUTEVALUE": "864"
}, {
    "ATTRIBUTETANO": 600400348,
    "ATTRIBUTEVALUE": "1"
}]
