POST

Request URL Template

http://{HostName}/{ServiceName}/Feature/{FNO}/{FID}/{CNO}/Geometry?pCONF={PCONF}&pLCID={PLCID}&pJOB={PJOB}&apiVersion={apiVersion}[ &ActiveJob={job name} ]

http://{HostName}/{ServiceName}/Feature/{FNO}/{FID}/{CNO}/{CID}/Geometry?pCONF={PCONF}&pLCID={PLCID}&pJOB={PJOB}&apiVersion={apiVersion}[ &ActiveJob={job name} ]

Request Parameters

Parameter Name Description
FNO The input requires FeatureNumber
FID The input requires FeatureIdentifier
CNO The input requires ComponentNumber
Geometry The input requires WKTGeometry
PCONF The input requires Connected GTech configuration
PLCID The input requires Locale language indentifier of client
pJOB GTech job identifier. Use of pJob parameter is deprecated. If specified, it is mapped to ActiveJob={pJob value}.
apiVersion GTDWS service version. Supported versions are 2.1.0 and 2.2.0.
ActiveJob Optional. Edits from this request are added to the job's pending edits.

Request Body format

{"data": "POINT (4502300.50 5925570.20)" }

When there is an error from package related to metadata, a generic error will be shown. The Oracle error along with the ORA error code will be logged in database.

Sample Request

http://nodename/IWMUTEST12B/Feature/306/7680002/30602/Geometry?apiVersion=2.2.0

Sample Response

{"data":"POINT (7444192.63276376 1047047.55949793)"}
