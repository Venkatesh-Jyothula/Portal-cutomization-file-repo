AttributeUpdate

Inserts and updates the record for the selected attributes record.

PUT

Request URL Template

/Feature/Attribute?pCONF={PCONF}&pLCID={PLCID}&pJOB={PJOB}&apiVersion={apiVersion}[&ActiveJob={job name}][&skipfi={skipfi}]

Request Parameters

Parameter Name Description
PCONF Connected GTech configuration
PLCID Locale language indentifier of client
PJOB GTech job identifier
apiVersion GTDWS service version. Supported versions are 2.2.0 and 2.3.0.
ActiveJob Optional. Edits from this request are added to the job's pending edits.
skipfi Optional. 1 or true to bypass Functional Interface invocation. If not specified, parameter skipfi defined in web.config appSettings section is used. If not defined default, value 0 (false) is used.

Picklist now supports Restricted and Unrestricted behavior on picklist attribute. We need to pass G3E_TANO and its value in post body from version 2.3.0.

For restricted picklist, the service will validate the "NEWVALUE" across the picklist. If "NEWVALUE" doesn't exists service throws the exception. For Unrestricted picklist, the service will not validate the "NEWVALUE" across the picklist.

When there is an error from package related to metadata, a generic error will be shown. The Oracle error along with the ORA error code will be logged in database.

Sample Request for 2.3.0

http://{HostName}/{GTDWS ServiceName}/Feature/Attribute?apiVersion=2.3.0&pLCID=0009

Sample Request Body

{
    "items": [{
            "TANO": 173010201,
            "FID": 231949887,
            "FNO": 17300,
            "CID": 1,
            "NEWVALUE": "PROT_OUT_HALF"
        }
    ]
}

Sample Request

http://{HostName}/{GTDWS ServiceName}/Feature/Attribute?apiVersion=2.2.0&pLCID=0009

Sample Request Body

{
    "items": [{
            "ANO": 220106,
            "FID": 231962958,
            "FNO": 2200,
            "CID": 1,
            "NEWVALUE": "ARMCO PIPE"
        }
    ]
}

Sample Response

{
  "items": [
    {
      "FID": 231962958,
      "CID": 1
    }
  ]
}

POST

Request URL Template

/Feature/Attribute?pCONF={PCONF}&pLCID={PLCID}&pJOB={PJOB}&version={VERSION}[&ActiveJob={job name}][&skipfi={skipfi}]

Request Parameters

Parameter Name Description
PCONF Connected GTech configuration
PLCID Locale language indentifier of client
PJOB GTech job identifier
apiVersion GTDWS service version. Supported versions are 2.1.0, 2.2.0 and 2.3.0.
ActiveJob Optional. Edits from this request are added to the job's pending edits.
skipfi Optional. 1 or true to bypass Functional Interface invocation. If not specified, parameter skipfi defined in web.config appSettings section is used. If not defined, default value 0 (false) is used.

Picklist now supports Restricted and Unrestricted behavior on picklist attribute. We need to pass G3E_TANO and its value in post body from version 2.3.0.

For restricted picklist, the service will validate the "NEWVALUE" across the picklist. If "NEWVALUE" doesn't exists service throws the exception. For Unrestricted picklist, the service will not validate the "NEWVALUE" across the picklist.

When there is any error from package related to metadata, generic error will be shown and Oracle error will be logged in database.

To validate hyperlinks, the called must pass "ISHYPERLINK" parameter and its value in post body. Passing 1 is for validating shared path and 2 is for validating web URL.

Sample Request for 2.3.0

http://{HostName}/{GTDWS ServiceName}/Feature/Attribute?apiVersion=2.3.0&pLCID=0009

Sample Request Body

{
    "items": [{
            "TANO": 173010201,
            "FID": 231949887,
            "FNO": 17300,
            "CID": 1,
            "NEWVALUE": "PROT_OUT_HALF",
            "ISHYPERLINK": "2"
        }
    ]
}

Sample Response

{
  "items": [
    {
      "FID": 231962958,
      "CID": 1
    }
  ]
}
