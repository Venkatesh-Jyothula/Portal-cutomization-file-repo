GetPicklist

Gets the picklist records for the selected attribute number along with multicolumn value.

GET

Request URL Template

http://{HostName}/{ServiceName}/PickList/{ANO}?pLCID={PLCID}&pIndex={PINDEX}&pSize={PSIZE}&pFilter={PFILTER}}&apiVersion={apiVersion}

Request Parameters

Parameter Name Description
PLCID Locale language indentifier of client
PINDEX Paging index number
PSIZE Paged records to be returned
PFILTER Filter string for picklist
apiVersion GTDWS service version. Supported versions are 2.2.0 and 2.3.0.

Multicolumn Picklist

Picklist GET and POST APIs support multicolumn. In the response of this API, ATTRIBUTEADDITIONAL is for additional column values. The order of these values depend on G3E_ATTRIBUTEPNOADDITIONFIELDS property returned in response of DialogTab for this ANO\TANO.

For type ahead filtering, if filter needs to be done on reserved characters, partially encoded form needs to be sent from client. Specially partial encoding needs to be done for "+","/"

For example: reserved character "+" needs to be sent like %2B, "/" needs to be sent with %2f.

http://{HostName}/{GTDWS ServiceName}/PickList/7118?pLCID=0009&pFID=133167742&apiVersion=2.2.0&pFilter=Z%2b

When there is an error from package related to metadata, a generic error will be shown. The Oracle error along with the ORA error code will be logged in database.

Sample Request

http://{HostName}/{GTDWS ServiceName}/PickList/208010008?apiVersion=2.2.0&pFilter=building

Sample Response

{
    "items": [{
        "ATTRIBUTEPNOKEY": "PP",
        "ATTRIBUTEPNOVALUE": "PP",
        "ATTRIBUTEADDITIONAL": [
            "SPECIES1",
            "35",
            "5",
            "8",
            "4"
        ]
    }]
}
