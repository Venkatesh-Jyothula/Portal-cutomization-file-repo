Dialog

Read feature dialog metadata information for a given feature number and type. pType is required to get the data.

GET

Request URL Template

http://{HostName}/{GTDWS ServiceName}/Dialog/{FNO}/{FID}?pCONF={PCONF}&pLCID={PLCID}&pUSER={PUSER}&pTYPE={PTYPE}&apiVersion={apiVersion}

Request Parameters

Parameter Name Description
FNO Feature Number
FID Feature ID to apply dialog metadata filters
PCONF Connected GTech configuration
PLCID Locale language indentifier of client
PUSER Connected user role
PTYPE Dialog type
apiVersion GTDWS service version. Supported versions are 2.2.0 and 2.3.0.

When there is an error from package related to metadata, a generic error will be shown. The Oracle error along with the ORA error code will be logged in database.

Sample Request

http://{HostName}/{GTDWS ServiceName}/Dialog/306/7680002/Review?apiVersion=2.2.0
