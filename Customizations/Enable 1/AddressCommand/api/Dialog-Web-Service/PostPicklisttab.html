PostPicklisttab

This API is to support field value filter along with multicolumn. The response includes key, value, and additional columns value for a given G3E_TANO.

POST

Request URL Template

http://{HostName}/{ServiceName}/PickList/{TANO}?pCONF={pCONF}&pLCID={PLCID}&pJOB={pJOB}&Index={PINDEX}&Size={PSIZE}&pFID={PFID}&pCID={PCID}&Filter={PFILTER}&apiVersion={apiVersion}

Request Parameters

Parameter Name Description
pCONF Connected GTech configuration
pLCID Locale language indentifier of client
pJOB GTech job identifier
PINDEX Paging index number
PSIZE Paged records to be returned
PFID Feature Identifier used for Fieldvalue Filtering
PCID Compoenent Identifier used for Fieldvalue Filtering
PFILTER Filter string for Picklist
apiVersion GTDWS service version. Supported versions are 2.2.0 and 2.3.0.

FieldValue Filter

When G3E_FIELDVALUEFILTER for TANO is not null, this API helps to retrieve the filtered picklist. In the request, TANO along with the involved TANOs and its values should be passed in request body. The response returns the filtered Picklist.

For example: TANO - 208010008 has G3E_FIELDVALUEFILTER set. In request body, the TANO's and selected values are sent. The service will evaluate the filter using these values.

If FID is passed, field value filter is evaluated by considering database values for missing TANOs.

Case 1: FID is null

TANO and value of all attributes in the filter need to be sent in post body.

Case 2: FID and CID are not null

TANO and value of all attributes in the filter need not to be sent in post body. The missing values will be considered from database. This is applicable when Field value filter attributes are available in multiple tabs.

Note: When CID is null/invalid first available record for the given FID will be considered.

For type ahead filtering, if filter needs to be done on reserved characters, partially encoded value needs to be sent from client. Specially partial encoding needs to be done for "+","/"

For example: reserved character "+" needs to be sent like %2B, "/" needs to be sent with %2f.

http://{HostName}/{GTDWS ServiceName}/PickList/7118?pLCID=0009&pFID=133167742&apiVersion=2.2.0&pFilter=Z%2b

When there is an error from package related to metadata, a generic error will be shown. The Oracle error along with the ORA error code will be logged in database.

Sample Request

http://{HostName}/{GTDWS ServiceName}/picklist/300100172?pLCID=0009&FID=133167742&CID=1&apiVersion=2.2.0

Sample Request

http://{HostName}/{GTDWS ServiceName}/PickList/22010101?apiVersion=2.2.0&FID=231957315&pFilter=ARM
