FeatureRelationshipInformation

Gets the feature relationships information for the selected feature number.

GET

Request URL Template

http://{HostName}/{ServiceName}/RelationshipList/{FNO}?pCONF={PCONF}&pLCID={PLCID}&pTYPE={PTYPE}&apiVersion={apiVersion}

Request Parameters

Parameter Name Description
PCONF Connected GTech configuration
PLCID Locale language indentifier of client
PTYPE Relationship type
apiVersion GTDWS service version. Supported versions are 2.2.0 and 2.3.0.

When there is an error from package related to metadata, a generic error will be shown. The Oracle error along with the ORA error code will be logged in database.

Sample Request

http://{HostName}/{GTDWS ServiceName}/RelationshipList/14900?apiVersion=2.2.0&pTYPE=Review

Sample Response

{
     "items": [{
         "RFNO": 24,
         "USERNAME": "Review"
     }, {
         "RFNO": 23,
         "USERNAME": "All"
     }]
 }
