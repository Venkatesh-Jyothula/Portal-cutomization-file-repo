Get Geometry

Get feature geometry in WKT format.

Request

URI

GET /Feature/{FNO}/{FID}/{CNO}/Geometry[?pCONF={PCONF}&pJOB={PJOB}&apiVersion={apiVersion}]&[ Jobs={list of job names} | ActiveJob={job name}]

GET /Feature/{FNO}/{FID}/{CNO}/{CID}/Geometry[?pCONF={PCONF}&pLCID={PLCID}&pJOB={PJOB}&apiVersion={apiVersion}]&[ Jobs={list of job names} | ActiveJob={job name}]

Parameters

Parameter Name Description
FNO Feature Number
FID Feature Identifier
CNO Component Number
CNO Component Identifier
PCONF Connected GTech configuration
PJOB GTech job identifier. Use of pJob parameter is deprecated. If specified, it is mapped to ActiveJob={pJob value}.
apiVersion GTDWS service version. Supported versions are 2.2.0 and 2.3.0.
ActiveJob Optional. Edits from this request are added to the job's pending edits.
Jobs Optional comma separated list of jobs whose pending edits will particate in the operation.

Response

Normal response (200)

Geometry in WKT format, wrapped in JSON.

{"data":"POINT (7444192.63276376 1047047.55949793)"}

Invalid operation (500)

When there is an error from package related to metadata, a generic error will be shown. The Oracle error along with the ORA error code will be logged in database.

Examples

Sample Request

http://{HostName}/{GTDWS ServiceName}/Feature/306/7680002/3060/Geometry?apiVersion=2.2.0&Jobs=JOBNO8093
