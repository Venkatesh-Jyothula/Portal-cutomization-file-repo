DeleteFeatures

Deletes the selected feature instance.

GET

Request URL Templates

http://{HostName}/{ServiceName}/Feature/{FNO}/{FID}/Delete?pCONF={PCONF}&pJOB={PJOB}&apiVersion={apiVersion}[&ActiveJob={job name}]

http://{HostName}/{ServiceName}/Feature/{FNO}/{FID}/{CNO}/Delete?pCONF={PCONF}&pJOB={PJOB}&apiVersion={apiVersion}[&ActiveJob={job name}]

http://{HostName}/{ServiceName}/Feature/{FNO}/{FID}/{CNO}/{CID}/Delete?pCONF={PCONF}&pJOB={PJOB}&apiVersion={apiVersion}[&ActiveJob={job name}]

Request Parameters

Parameter Name Description
FNO The input requires FeatureNumber
FID The input requires FeatureIdentifier
CNO The input requires ComponentNumber
CID The input requires ComponentIdentifier
PCONF The input requires Connected GTech configuration
PJOB GTech job identifier. Use of pJob parameter is deprecated. If specified, it is mapped to ActiveJob={pJob value}.
apiVersion GTDWS service version. Supported versions are 2.2.0 and 2.3.0.
ActiveJob Optional. Edits from this request are added to the job's pending edits.

When there is an error from package related to metadata, a generic error will be shown. The Oracle error along with the ORA error code will be logged in database.

Sample Request

http://{HostName}/{GTDWS ServiceName}/Feature/14900/231952573/63/2/Delete?apiVersion=2.2.0

Sample Response

{
    "items": [{
        "FNO": 12678967.543233,
        "FID": 12678967.543233,
        "CNO": 12678967.543233,
        "CID": 12678967.543233
    }]
}
