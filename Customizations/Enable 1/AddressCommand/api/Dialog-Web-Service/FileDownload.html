FileDownload

Downloads file to shared data storage.

GET

Request URL Template

http://{HostName}/{ServiceName}/File?pCONF={PCONF}&pLCID={PLCID}&pJOB={PJOB}&pANO={PANO}&pFID={PFID}&pCID={PCID}&apiVersion={apiVersion}&[ Jobs={list of job names} | ActiveJob={job name}]

Request Parameters

Parameter Name Description
PCONF Connected GTech configuration
PLCID Locale language indentifier of client
PJOB GTech job identifier. Use of pJob parameter is deprecated. If specified, it is mapped to ActiveJob={pJob value}.
PANO Picklist attribute number
PFID Feature Identifier
PCID Component identifier
apiVersion GTDWS service version. Supported versions are 2.2.0, 2.3.0 and 2.4.0.
ActiveJob Optional. Edits from this request are added to the job's pending edits.
Jobs Optional comma separated list of jobs whose pending edits will particate in the operation.

Downloads the file with filename when fullpath is specified as attribute value. If the File is not available in Fullpath, search in the OtherPaths section of FileUNC.xml

When there is an error from package related to metadata, a generic error will be shown. The Oracle error along with the ORA error code will be logged in database.

Sample Request

http://{HostName}/{GTDWS ServiceName}/File?apiVersion=2.4.0&pLCID=0009&pANO=6306&pFID=231952219&pCID=1

The requested file will be opened in new tab.

Sample Request

http://{HostName}/{GTDWS ServiceName}/File?apiVersion=2.2.0&pLCID=0009&pANO=6306&pFID=231952219&pCID=1

The requested file will be downloaded.
