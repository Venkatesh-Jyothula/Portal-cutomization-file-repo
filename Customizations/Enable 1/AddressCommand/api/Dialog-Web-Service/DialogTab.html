DialogTab

Gets the dialog tab attributes information for the selected dialog tab number. Supports multiple triggers.

GET

Request URL Template

http://{HostName}/DialogTab/{DTNO}/{FID=null}/{CID=null}?pCONF={pCONF}&pLCID={pLCID}&pUSER={pUSER}&pJOB={pJOB}&Index={pIndex}&Size={pSize}&apiVersion={apiVersion}&[Jobs={list of job names} | ActiveJob={job name}]

Request Parameters

Parameter Name Description
DTNO Dialog tab ID
pCONF Connected GTech configuration
pLCID Locale language indentifier of client
pUSER Connected user role
pJOB GTech job identifier. Use of pJob parameter is deprecated. If specified, it is mapped to ActiveJob={pJob value}.
Index Paging index number
Size Paged records to be returned
apiVersion GTDWS service version. Supported versions are 2.2.0 and 2.3.0.
ActiveJob Optional. Edits from this request are added to the job's pending edits.
Jobs Optional comma separated list of jobs whose pending edits will particate in the operation.

X-Paging-Index, X-Paging-Size can be passed as headers, instead of sending to outgoing requests.

To get multiple trigger filters version 2.3.0 needs to be used. G3E_filter is string[] in 2.3.0 and string in 2.2.0

When there is an error from package related to metadata, a generic error will be shown. The Oracle error along with the ORA error code will be logged in database.

Sample Request

http://{HostName}/{GTDWS ServiceName}/DialogTab/300103/262258/1?pLCID=0009&Jobs=JOBNO11659&apiVersion=2.3.0
