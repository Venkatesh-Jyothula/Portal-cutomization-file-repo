DetailWindows

Retrieves NetWorks detail windows by providing FeatureId and Feature number(optional). Schematic details can also be obtained by setting an optional parameter Schematic.

GET

Request URL Template

http://{HostName}/{GTDWS ServiceName}/DetailWindows/{PFNO}/{PFID}?pCONF={PCONF}&pLCID={pLCID}&Index={pIndex}&Size={pSize}&schematic={isSchematic}&apiVersion={apiVersion}

Request Parameters

Parameter Name Description
pFNO The input contains required feature number string
pCONF The input contains required Connected GTech configuration string
pLCID The input contains required Locale language indentifier of client string
pFID The input contains required Feature identifier string
pIndex The input contains required Paging index number
pSize The input contains required Paged records to be returned
Schematic The input contains whether it is schematic or not
apiVersion GTDWS service version. Supported versions are 2.2.0 and 2.3.0.

X-Paging-Index, X-Paging-Size can be passed as headers, instead of sending to outgoing requests.

When there is an error from package related to metadata, a generic error will be shown. The Oracle error along with the ORA error code will be logged in database.

Sample Request

http://{HostName}/{GTDWS ServiceName}/DetailWindows/217/4592323?apiVersion=2.2.0
