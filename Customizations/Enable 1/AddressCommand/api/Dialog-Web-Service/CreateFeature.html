CreateFeature

Creates a new instance of feature for the input feature number.

The method requires an entry in table NWG_CREATE_FEATURE for each G3E_FNO which is created using this API. The GIN_PROCEDURE_NAME must be set to a procedure with the following signature:

PROCEDURE <name> (PFNO IN NUMBER, PUDTKEYTABLE OUT TUDTKEYTABLE)

NetWorks is delivered with a generic procedure CAO_CREATE_FEATURE.

GET

Request URL Template

http://{HostName}/Feature/{FNO}/Create/pCONF={PCONF}&pLCID={PLCID}&pJOB={PJOB}&apiVersion={apiVersion}[&ActiveJob={job name}]

Request Parameters

Parameter Name Description
FNO FeatureNumber
pCONF Connected GTech configuration
pLCID Locale language indentifier of client
pJOB GTech job identifier. Use of pJob parameter is deprecated. If specified, it is mapped to ActiveJob={pJob value}.
apiVersion GTDWS service version. Supported versions are 2.2.0 and 2.3.0.
ActiveJob Optional. Edits from this request are added to the job's pending edits.

When there is an error from package related to metadata, a generic error will be shown. The Oracle error along with the ORA error code will be logged in database.

Sample Request

http://{HostName}/{GTDWS ServiceName}/Feature/306/Create?apiVersion=2.2.0&pLCID=0009&pJOB=JOBNO8093&ActiveJob=JOBNO8093
