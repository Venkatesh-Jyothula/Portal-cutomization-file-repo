FeatureByPolygon

Gets and updates the feature list FNO, FID, username for given polygon.

GET

Request URL Template

http://{HostName}/{ServiceName}/Query/FeatureByPolygon?pCONF={PCONF}&pLCID={PLCID}&pWKTGeometry={SWKTGEOMETRY}&apiVersion={apiVersion}&[Jobs={list of job names} | ActiveJob={job name}]

Request Parameters

Parameter Name Description
PCONF Connected GTech configuration
PLCID Locale language indentifier of client
PJOB GTech job identifier. Use of pJob parameter is deprecated. If specified, it is mapped to ActiveJob={pJob value}.
SWKTGEOMETRY Geometry
apiVersion GTDWS service version. Supported versions are 2.2.0 and 2.3.0.
ActiveJob Optional. Edits from this request are added to the job's pending edits.
Jobs Optional comma separated list of jobs whose pending edits will particate in the operation.

When there is an error from package related to metadata, a generic error will be shown. The Oracle error along with the ORA error code will be logged in database.

Sample Request

http://{HostName}/{GTDWS ServiceName}/Query/FeatureByPolygon?pWKTGeometry=POLYGON ((2181625.4002508 397675.567351134, 2181625.57025114 397694.541389083, 2181613.00622601 397694.654389308, 2181612.83522567 397675.68035136, 2181625.4002508 397675.567351134))

Sample Response

{
  "items": [
    {
      "FNO": 100,
      "FID": 3766435,
      "USERNAME": "Building No. \nType: "
    }
  ]
}

POST

Request URL Template

http://{HostName}/{ServiceName}/Query/FeatureByPolygon?pCONF={PCONF}&pLCID={PLCID}&apiVersion={apiVersion}&[ Jobs={list of job names} | ActiveJob={job name}]

Request Parameters

Parameter Name Description
PCONF Connected GTech configuration
PLCID Locale language indentifier of client
PJOB GTech job identifier. Use of pJob parameter is deprecated. If specified, it is mapped to ActiveJob={pJob value}.
apiVersion GTDWS service version. Supported versions are 2.1.0 and 2.2.0.
ActiveJob Optional. Edits from this request are added to the job's pending edits.
Jobs Optional comma separated list of jobs whose pending edits will particate in the operation.

Sample Request

http://{HostName}/{GTDWS ServiceName}/Query/FeatureByPolygon?pLCID=0009&apiVersion=2.2.0

Request Body format

}

      "USERNAME": "Building No. \nType: "
