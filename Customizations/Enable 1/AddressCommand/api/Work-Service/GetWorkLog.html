GetWorkLog

Get log of work request processing.

Request

URI

GET /work/{workload}/{wid}/log?start={start}&count={count}

Parameters

Name Type Mandatory Description
workload String Y Workload type (e.g. convertcad, print, trace)
wid String Y Work request identifier, returned originally from SubmitWork
start Integer Y Index of the first log line returned (0-based). Default is 0.
count Integer Y Number of log lines to return. Default is 1000, maximum is 100000.

Request body

N/A

Response

Response body contains payload as returned from processing. Format depends on the workload type.

Example:

{
    "start": 0,
    "total": 10,
    "lines": [
        "Starting...",
        "Sleeping for 5 seconds...",
        "5",
        "4",
        "3",
        "2",
        "1",
        "0",
        "Writing response to tmp8781.tmp",
        "Exiting with 0."
    ]
}

Bad request (400) - Invalid identifier

Returned when the request has invalid parameters.

{
    "success": false,
    "errorCode": "ERR_NO_SUCH_WORK_REQUEST",
    "errorMessage": "Work request identifier was not found"
}

Authentication failure (401)

Returned when authorization token is missing or invalid.

Server error (500)

Returned when internal processing in the Work server fails.

{
    "success": false,
    "ErrorCode": "ERR_INTERNAL_ERROR",
    "ErrorMessage": "Error details"
}
